# 将近代中国经济史置于全球大萧条与白银流动的坐标系中，解密传统银本位如何从避风港沦为扼杀民国经济的绞索

日本著名经济史学家、东京大学教授城山智子在这部极具开创性的学术专著中，彻底改写了近代中国民国经济史的研究范式。长期以来，中国近代史学界在解释二十世纪三十年代南京国民政府时期的经济剧变时，往往陷入两种狭隘的解释框架：要么单纯归咎于帝国主义列强的政治侵略与关税压迫，要么将其完全归结为国共内战与国民党官僚资本的腐败掠夺。城山智子突破了这种政治单因论，将近代中国深深嵌入二十世纪三十年代全球大萧条与国际货币体系崩溃的宏大网络之中，用扎实的海关贸易统计、钱庄账本与棉纺织企业一手档案，展现了一个实行银本位的后发国家，如何在全球货币剧烈波动的巨浪中遭遇被动绞杀与绝地重构。

全书的论述围绕近代中国金融货币体制的生死蜕变层层展开。其一是二十年代末中国经济在白银贬值掩护下的短暂黄金十年，当欧美资本主义世界在金本位崩溃与通货紧缩中苦苦挣扎时，中国因实行银本位、国际银价暴跌而享受了长达数年的货币贬值出口红利。其二是一九三三年美国罗斯福新政出台《购银法案》，为了迎合国内西部白银产区议员的政治私利，美国财政部在国际市场上疯狂高价收购白银，引发国际银价暴涨，导致中国沿海白银大量外流、通货急剧紧缩、钱庄倒闭潮与乡村经济大破产。其三是南京国民政府在危机倒逼下，于一九三五年十一月断然推行的法币改革，彻底废除流通千年的银本位，收归货币发行权，建立起现代国家信用纸币体制。其四是法币改革带来的国家统制经济扩张，为随后长达八年的全面抗日战争提供了至关重要的战时财政与金融动员基础，但同时也为战后财政失控与恶性通货膨胀埋下了致命祸根。

这部著作是近代中国制度变迁史的典范之作。它以无可辩驳的经济实证证明，后发国家的现代化不仅关乎政治政权的更迭，更根本地取决于其能否在全球资本主义的金融风暴中，建立起具备独立防御能力的现代国家金融基础设施。

# 美国购银法案白银外流账本、上海钱庄倒闭潮与无锡棉纺业停工的历史实录

全书的第一个坚实经济史证据指向一九三四年美国《购银法案》对中国货币存量的物理抽水，即｜美国购银法案引发的中国沿海白银外流与通缩通缩螺旋｜。城山智子通过细致比对上海江海关白银进出口月度报表证明，一九三四年一年之内，自上海港合法与走私外流的白银净额高达数亿元，直接抽干了中国现代金融体系近三分之一的准备金基数。作为货币本位的白银大量逃逸，导致上海市场银根奇紧，拆息率暴涨，整个国家的物价指数在短短两年内暴跌超过百分之二十，商业交易陷入完全停滞。

第二个实证是一九三五年上海钱庄业的系统性雪崩，即｜上海传统钱庄信用网络断裂与现代华资商业银行的霸权接管｜。城山智子深入挖掘了上海钱业公会的内部档案。传统钱庄极度依赖基于熟人社会的信用庄票发放贷款。在严酷的通货紧缩与存款挤兑下，不仅钱庄的庄票无法承兑，而且其长期向民族工商业发放的信用贷款全部沦为坏账。数十家百年老钱庄接连破产，标志着江南传统金融信用网络的彻底解体，现代拥有雄厚资本实力的华资大银行趁机彻底主导了金融话语权。

第三个实证聚焦于江南核心实体制造业的微观崩溃，即｜无锡申新棉纺织厂与江南蚕丝业在内外挤压下的全线停产破产潮｜。城山智子选取了荣氏家族申新纱厂与无锡丝茧业的真实经营报表。由于国内农产品价格暴跌，广大农村购买力彻底归零，导致城市工业品严重过剩；与此同时，白银升值使得中国棉纱在国际市场上丧失了全部价格竞争力，遭遇日本纺织业的降价倾销。双重打击之下，民族资本代表荣德生被迫将工厂质押给中国银行，民族工业在三十年代中期的全线溃败，直接倒逼国家力量全面介入经济救市。

# 货币非国家化脆弱性、输入型通缩传导与法币制度国家赋权三大演进齿轮

城山智子穿透宏观经济波动的表面数据，提炼出驱动近代中国从传统金融向现代统制经济跃迁的三大动力学机制。

第一齿轮是货币发行的非国家化与制度碎片化死穴。在法币改革之前，近代中国从来没有统一的国家主权货币。银两、银元、铜钱与形形色色的外国银行纸币同时流通，货币供应量完全由市场上的白银存量与国际银价自发决定，国家中央政权根本不具备通过调节货币供给来应对经济周期的能力。这种将通通命脉完全拱手让给国际金属价格波动的体制，使得中国经济在面对外部巨浪冲击时宛如不设防的裸奔者。

第二齿轮是城乡经济的货币信贷传导阻断机制。近代中国的经济结构存在着严重的二元断层：沿海开埠大都会与广袤传统乡村之间，依靠一套由白银、钱庄、典当铺与土特产商号构筑的脆弱信用链条相连。当沿海港口的白银被美国高价吸走后，紧缩效应迅速沿着棉花、生丝的收购网络反向传导至内地乡村。农民手里的粮食和棉花卖不出去，手里的白银货币被地主和高利贷者收紧，造成了骇人听闻的丰收成灾悲剧，加速了农村社会的全面破产与激进化。

第三齿轮是法币改革赋予防御性国家能力的大跃升。一九三五年十一月孔祥熙与宋子文主导的法币改革，是一次真正意义上的现代国家制度建构。通过宣布法币为唯一合法流通货币、实行白银国有化，并将法币汇率与英镑、美元挂钩，南京国民政府第一次成功收归了国家铸币权。这一改革不仅迅速终止了通货紧缩、拉动了经济复苏，更关键的是让中央政府拥有了直接通过发行国家信用纸币筹集战时军费的能力，成为中国能够支撑八年全面抗战的最重要隐秘经济底座。

# 从白银风暴的始末直抵主权国家在现代全球金融体系中的立国之本

顺着城山智子对大萧条时期中国经济的深入解剖，我们直抵后发国家现代化最根本的制度命门。

第一步追问击碎了纯粹金属本位更安全的陈旧迷思。很多人天真地认为，有真金白银做后盾的货币最值得信赖，纸币则是政府随意通胀的谎言工具。城山智子证明，金属本位的最大危险在于其供给量完全受制于物理开采与别国政策。当别国利用金融强权任意操控白银黄金价格时，一个恪守金属本位的中小国家就会被硬生生抽干流动性而死。现代经济要想自立，就必须建立在主权国家信用背书的法定纸币基础之上。

第二步揭示了现代国家政权建设与金融体系集权的孪生关系。任何后发国家想要抵御外部侵略、推进工业化，就必须具备强大的资源动员能力。法币改革绝非单纯的币制技术调整，它是一场深刻的财政集权革命。它剥夺了军阀与民间金融家的铸币特权，将全社会的流动性命脉集中到中央银行手中，为现代强力国家机器的诞生奠定了财政基石。

第三步确立了不受约束的国家印钞权对社会契约的终极反噬。法币制度是一把威力巨大却极度危险的利刃。在战时紧急状态下，它赋予了政府无尽的动员力；但由于缺乏独立的中央银行制度与民主宪政的预算约束，当抗战胜利后国民党政权面临巨大财政赤字时，法币制度便迅速滑向了无底线的恶性通货膨胀，最终在一九四八年金圆券的风暴中彻底摧毁了自身的统治合法性。

# 六大货币与国家治理推演：从输入型金融风险防御到核心资产储备法则

推演一，主权国家如何抵御霸权货币的外部溢出效应？必须坚决捍卫国家独立的货币政策自主权，建立充足且多元化的外汇储备资产池，严密监控关键战略金属与国际大宗商品的资本外流通道。

推演二，面对通货紧缩恶性螺旋时的第一救市原则是什么？当全社会陷入借贷意愿低迷、物价持续下跌的通缩陷阱时，切勿迷信市场的自发调整，国家必须果断通过扩张性财政与货币政策注入流动性，强行托底信贷底盘。

推演三，如何处理传统民间金融与现代金融监管的融合？在推进金融现代化集权的过程中，切勿通过行政禁令简单粗暴地消灭具有深厚地方信任根基的传统民间金融网络，必须提供有效的普惠金融替代工具，防止底层信贷断裂。

推演四，宏观调控如何兼顾沿海大都会与内陆腹地的利益平衡？高度警惕沿海金融中心的政策变动对广袤腹地农村产生的非对称放大冲击，建立从沿海到内陆的财政转移支付与定向信贷滴灌机制。

推演五，组织在面临外部核心结算工具断裂时如何自救？尽早建立多币种或非美元资产的备份结算体系，与核心供应链伙伴签订基于本币互换或实物资产对冲的长期合作框架，降低单一货币依附度。

推演六，如何防范信用法币体制走向不可逆的恶性通胀？国家信用纸币的唯一最终锚点是全社会的综合生产力与税收履约信用，严禁将央行印钞机直接充当弥补财政经常性赤字的无底线提款机。

# 审视城山智子对南京政府经济统制正面效应的高估与对基层腐败的滤镜

城山智子的专著代表了战后日本中国学派极高的实证水准，但读者在阅读时仍需客观辨析其论证局限。

首先，全书对一九三五年法币改革的制度创新给予了极高评价，充分肯定了其在抵御通缩与支持抗战中的积极作用。然而这种宏观叙事在一定程度上掩盖了法币改革过程中，蒋宋孔家族官僚资本利用内幕交易大肆吞并华资民营银行与民族企业的巧取豪夺真相，对四大家族金融垄断对民营资本活力的扼杀剖析不够充分。

其次，全书的实证数据高度集中于上海、无锡等江南经济核心区以及部分通商口岸。对于幅员辽阔的华北、西北、西南等军阀割据区域，法币在多大程度上真正穿透了地方杂钞的封锁，其论证深度略显不足，存在以江南一隅推导全国全局的微观样本偏差。

行动触发：当外部主要经济体出台极端的货币宽松或激进加息政策时，立即排查自身业务资产负债表中的跨国汇率敞口，全面启动本币套期保值对冲工具。

# 为什么美国国会通过一个买银子的法案，就能把几万公里外中国农村的农民活活逼死？

很多人在读民国历史的时候，怎么也想不明白：一九三几年美国在闹经济大萧条，美国总统罗斯福在华盛顿签了一张纸，说要帮美国西部的矿工多买点白银，怎么过了几个月，中国江南的桑蚕养殖户和纺织厂老板就纷纷跳河自杀了？城山智子在书里把这套神奇的货币传导链讲得像水管流水一样清楚。

当时的中国是一个实行银本位的国家。什么叫银本位？就是你手里的铜板、纸票，最终都得按重量换成白银，白银就是全国流通的真正货币。这时候全世界其他大国全都已经不用白银做货币了，只有中国还在用。本来相安无事，结果一九三四年美国经济大萧条，罗斯福为了讨好几个西部产银大州的议员，通过了《购银法案》，宣布美国政府用远高于市场的高价在全世界狂收白银。

这下天塌了。全上海的投机客、外国银行和走私贩子全疯了：我把中国的白银运到美国去卖，转手就能赚大钱啊！于是一箱箱的白银被装上轮船运往美国，几个月时间，中国市面上的白银被抽走了三分之一。市面上没有银子，货币瞬间变得极其金贵，物价直接跌进冰窟窿。农民辛辛苦苦种出一担棉花，去年能卖十块银元，今年只能卖三块，连买化肥的本钱都不够；城里的棉纺织厂做出来的布堆在仓库里没人买得起，工厂只能停工关门。全中国的经济电路，就因为唯一的导电金属被美国抽干了，瞬间全面短路。这就是后发小国如果不掌握自己的货币主权，在国际金融大鳄面前宛如蝼蚁的残酷现实。

# 一个国家如果没有真正属于自己的独立主权货币，哪怕手握再多的金银财宝，最终也只是在给别国的货币政策充当无处逃生的蓄水池

《大萧条时期的中国》彻底终结了关于近代民国黄金十年的浪漫虚火。它用无可辩驳的经济事实告诫我们：一个没有现代金融防御纵深的国家，任何依靠外部红利带来的繁荣都不过是过眼云烟，唯有将金融命脉牢牢掌握在国家自主的制度底盘之上，才能在风云变幻的世界经济恶浪中立于不败之地。
