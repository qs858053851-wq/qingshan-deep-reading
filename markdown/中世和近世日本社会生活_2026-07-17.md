# 中世和近世日本社会生活

从镰仓幕府建立到德川幕府倒台，差不多七百年。我们对这七百年的印象基本被武士包办了：刀、切腹、忠诚、樱花。迪尔这本书开篇就要拆这个印象。他说，写这段日本史的人"注意力几乎全部集中于武士阶级身上"，好像那是一个平和稳定的武士社会。而他要写的，是各阶层之间和阶层内部数不清的纷争，是佃农、店主、僧侣、贱民、艺人怎么过日子。武士当然也写，但武士只占十二章里的一章。

序言里有个例子把他的方法讲透了。十六世纪茶道兴起，茶人们到哪里找美学灵感？不在宫廷，在农家。简朴的农民住宅、实用的储物柜，反过来启发了茶器的制作和茶室的搭建。用作者的话说，"随着富有阶层开始在无权无势的阶层中寻找艺术灵感，这些简朴的用品被提升到了一个新的美学高度"。日本美学里最著名的那点侘寂味道，源头是穷人的日常。这本书整个就是这么写的：从边缘照见中心。

### 十二章怎么铺

结构有讲究，从骨头到皮肤：先给时间轴和历史人物（第一章），再铺土地与人口（第二章），然后是双轨的统治结构（第三章）：京都的天皇朝廷管名分，幕府的武家机构管实权，两套班子并行了近七百年。第四章社会与经济是全书的承重墙，士农工商的身份制、税收、市场、货币都在这里。往后依次是武士与战争、宗教、儒学与教育、语言文学、能剧歌舞伎等表演艺术、茶道与建筑、五街道与驿站，最后落到最贴身的第十二章：婚姻、生育、饮食、发型、文身、节日、生老病死。

几个数字先立在这，感受一下这个社会的形状。农民约占总人口的八成到八成半，散布在全国六万三千个村庄里；室町时期最重的时候，幕府对农民产出征收近七成的税，一次歉收就是饥荒。近世末年，约三十八万人被划为贱民（秽多与非人），排除在士农工商之外。而有资格直接谒见将军的御家人，不过两千人上下。金字塔尖和塔基的比例，大致如此。

### 几幕好看的

发型与文身。头发在这个社会是身份证：社会地位、年龄、阶级、性别，全写在头上。文身的命运更曲折，1720 年以前它是刑罚，图案烙在罪犯的胳膊和脸上；元禄年间开始在妓女中流行，到十九世纪中期竟成了一门登峰造极的艺术。同一样东西，从耻辱标记走到时尚巅峰，用了一百多年。

伊势神宫。全日本最神圣的神社，供着天皇家的祖先天照大神的神镜。从七世纪末的天武天皇起，它每隔二十年拆掉重建一次，用同样的柏木、同样的样式，一丝不改。这套"式年迁宫"到今天还在办。一座永远崭新的千年古建筑，日本人对"永恒"的理解全在这个悖论里：不靠石头不朽，靠一代一代人把手艺重做一遍。

还有一件事，书里被作者用"具有讽刺意味的是"反复点到：幕府用朱子学把商人钉在四民的最底层，劝农民安贫乐道，要武士耻于谈钱。可两百年后，江户成了当时世界上数一数二的商业城市，武士向商人借债度日。这中间发生了什么，是全书最值钱的一条线，按下不表，第四层细讲。

结论：差在一个要害上。日本的封臣只是替远方主人管地的经理人，地不是他的。

怎么想到的：欧洲的骑士受封采邑，地是他的，传给儿子。日本不一样，书里写得清楚：封臣是任命的，代表住在远处的贵族、寺院或幕府高官行使职权；土地的所有者拥有地，人却不在地上。经理人想把职位变成实利，只有一条路：靠军事实力实际控制这块地。这个制度设计等于给全国每个地方军头都装了一台"做大做强"的发动机。后来的下克上、战国大名混战，不能怪日本人天性好斗，那是产权和控制权分家的必然结果。

边界：这是书里给的框架性对比，镰仓与江户两个时代的封臣实态差别很大，不能一概而论。

结论：因为分的不是地盘，而是功能：天皇管名分，幕府管刀把子，谁也离不开谁。

怎么想到的：书的政府章摆出两套完整的机构：京都朝廷有一套官制，幕府有一套武家官制，并行运转。幕府需要天皇授予"征夷大将军"的名分才算合法，天皇需要幕府的武力和供养才能存续。这像一家公司里董事会只管盖章、总经理握着全部业务，章和业务互相绑架，反而稳定。真正的危机都出现在有人想把两个功能合到自己一个人身上的时候。

边界：所谓稳定是宏观的，具体到南北朝那种两个天皇并立的年代，名分本身就是战场。

结论：恰恰是武士没仗可打的年代。武士道文本的密集出现，是失业焦虑的产物。

怎么想到的：看成书年代就够了。《五轮书》约 1643 年，《叶隐》1716 年，全在德川的长期和平里。书里点破了机制：德川将军把确立武士行为准则，当作激励武士为政府服务的办法。仗打完了，武士从战士变成领俸禄的官僚，可他的全部身份认同建立在"随时赴死"上。于是《叶隐》开篇反复念叨"武士之道即求死之道"——越是死不成的年代，越要把死挂在嘴上。意义感这个东西，现实里断了供，就会在纸面上加倍生产。

边界：武士道的源头（弓马之道）确实更早，这里说的是它被系统化、文本化的时间。

结论：不是。缝隙很多，而且最有意思的人恰恰住在缝隙里。

怎么想到的：作者专门写了一句，各阶层"并不是彼此绝对独立的"，僧侣就可能出身贵族，也可能出身农民。四民之外还有两头：上头的公家贵族和僧侣，下头近世末约三十八万贱民。贱民做的是处理尸体、皮革、行刑这些"不洁"的活，被制度性地隔离。可书里有个细节很扎眼：那些制定社会价值标准的武士精英，经常光顾贱民经营的娱乐场所。白天写规矩的人，晚上去规矩外面消遣。等级制的虚伪处，作者不评论，只陈列。

边界：缝隙归缝隙，对绝大多数人来说，出身还是命运。流动是例外，不是通道。

结论：不忍。这本书用一整节"一揆"证明：所谓平和稳定的武士社会，底下一直在烧。

怎么想到的：一揆就是结伙抗争。十五世纪，要求"德政"（免除债务）的土一揆爆发了约一百次，农民和佃户冲进京都烧当铺、毁债券；国一揆是地方武士联手赶走幕府派来的守护；一向一揆干脆是净土真宗的武装教团，握着地盘跟大名分庭抗礼。抗议的谱系从经济到政治到宗教，一应俱全。作者写这本书的靶子就在这：谁说这是个安分的社会？

边界：一揆多数被镇压。它证明反抗的频率；成功率是另一回事。

结论：幕府要的是控制大名，顺手把江户催成了消费之都、把全国的路修成了商业动脉。

怎么想到的：制度本身很简单，大名隔年必须到江户居住，向幕府效忠，妻儿常年留在江户当人质。可算算这笔账：两三百个大名，每家带着队伍每两年跑一个来回，路上要吃住，到了江户要维持体面的宅邸和排场。于是五条大道从日本桥辐射全国，东海道三百英里上排开五十三个驿站；于是江户成了经济中心，商人和手工业者跟着吃饱。一个纯粹的政治控制手段，副产品是全国统一市场的雏形。制度的实际后果，经常跟设计者的意图隔着十万八千里，这个例子可以当教科书。

边界：驿站里程和数字是英文原书的口径，具体数值以原书为准。

结论：不冲突，因为两套信仰各管一段：神道管生，佛教管死。

怎么想到的：书里的宗教章把分工摆得很清楚。孩子出生、五谷丰登、生意兴隆，去神社，稻荷神社的狐神就兼管农业和商业；丧事、来世、超度，找寺庙。日常里两者还互相渗透：佛教禁杀生的观念催生了街头卖笼中活物的小贩，买来放生，攒来世的福报。问一个江户人"你信哪个教"，他大概听不懂这个问题，就像问一个中国人清明扫墓和过年拜财神冲不冲突。信仰在生活里是分工表，不做单选题。

边界：基督教是例外，德川幕府对它是真禁绝，踏绘、驱逐、处刑，一样不少。

验证一下。双轨统治解释了七百年里"改朝"从不"换代"的怪象：将军换了一茬又一茬，天皇家从没断过。身份制解释了从发型到餐具的一切日常刻度，也解释了一揆的烈度，钉得越死，炸得越响。人钱照流解释了江户的繁荣、商人的坐大、武士的负债。三根线拧在一起，就是幕末的死局：靠身份制供养的武士阶层，在商品经济里破了产，最后倒幕的主力恰恰是穷武士。

```
名分（天皇）──┐
                ├─ 双轨稳定 ──┐
   实权（幕府）──┘             │
                              ├─→ 幕末总崩
   身份制（士农工商·钉死）──┐  │
                            ├──┘
   人流钱流（参勤交代·市场）─┘
        ↑ 制度想冻结社会，经济在底下悄悄解冻
```

第一层按下的那件事，现在讲。

德川幕府的立国意识形态是朱子学。按这套学问，社会分四等：武士居首，因为他们担纲道义；农民第二，因为他们生产粮食这个根本；手工业者第三；商人垫底，因为商人不生产任何东西，只是低买高卖，是道德上可疑的寄生者。幕府劝农民安贫，要武士耻于谈钱，武士的俸禄干脆不发钱，发稻米。

然后呢？书里那段话值得原样抄下来：正是这些贬抑货币的武士精英们的驱动，市场上才出现了他们渴望的奢侈品；他们将土地税征来的稻米换成货币，到市场和城里的商店购买所需的物品；最终结果是促进了批发和零售市场的发展，以及银行业和信贷系统的发展。

把这个链条摊开看。武士要体面，体面需要绸缎、刀装、茶器、宅邸；这些东西只有商人供得上；买东西要钱，武士手里只有米，于是大阪出现了把稻米换成货币的米市，米市催生了汇兑、放贷、期货，日本的金融业就这么被"耻于谈钱"的阶层亲手养大了。更妙的是参勤交代火上浇油：几百个大名每两年一次的豪华差旅，是当时全世界罕见的稳定消费流。江户的人口和商业跟着膨胀，商人越来越富。

而幕府的财政制度还停在农业时代：只对土地征税，不对商人的财富征税。意识形态上把商人贬到最底层，财政上却对他们的钱袋子无从下手，这两件事是同一个错误的两面：幕府始终不肯承认商业已经是国民经济的主干。于是出现了教科书级的倒挂：身份最高的武士向身份最低的商人借债，借到后来，大名的年贡还没收上来，就已经抵押给了大阪的米商。

攻一下这个结论：会不会是幕府太蠢，没人看见这个问题？不是。书里写到幕府多次改革，限制奢侈、赖掉武士欠商人的债、强令商人捐款，全是治标。真正的解法只有一个：改税基，向商业财富征税，可那等于官方承认朱子学的等级叙事破产。幕府宁可财政慢性失血，也不肯动意识形态的地基。这不是愚蠢，是制度性的不敢。

这件事值钱在哪？它是"官方叙事与经济现实脱节"的一个完整标本，从脱节的起点（用道德给职业排序）、中间的自欺（精英一边贬低市场一边喂养市场）、到结局（被自己不承认的力量掏空）。作者是个克制的手册作者，全书几乎不发议论，唯独在这条线上忍不住反复写"具有讽刺意味的是"。一个连议论都不肯发的人被逼得连说好几次"讽刺"，说明这条线在史料里实在太扎眼了。

顺着这个再看一眼那三十八万贱民和两千御家人：一个社会把八成人钉在土地上、把商人钉在道德底层、把不洁职业钉出四民之外，钉子越多，说明设计者越清楚：只要松一颗，人就会用脚投票。德川两百多年的和平，一半靠刀，一半靠钉子。而最后拔掉钉子的，不是外敌，是钉子缝里长出来的钱。

迪尔的动机写在序言里：他受不了"武士包办日本史"的写法。这个不满是有生产力的，全书最好的部分（贱民、一揆、町人文化、农家美学）都来自把镜头从武士身上挪开的那一下。

盲点也直说。第一，这毕竟是英文世界的入门手册，日本读者觉得常识的东西它花很多篇幅，真正的争议问题（比如天皇制为何能存续、锁国的代价）它只描述不深究。第二，全书按主题切片，代价是时间感模糊，镰仓的武士和幕末的武士在同一章里挨着出现，读者容易忘了中间隔着六百年。第三，我个人的不满：第十二章写性、写游廓（妓院区）时的笔调过于博物馆化，那是几十万真实女性的人生，值得比"娱乐文化"更重的笔墨。

跨域这么看：幕府对商人的困境，跟今天很多组织对"编制外力量"的困境是同一个结构。单位里最能干活的可能是外包和临时工，制度上却不给名分；名分给不了，激励就只能走灰色通道；灰色通道越粗，正式制度越空心。读德川的米市和大名的债务，等于提前看了这出戏的完整剧本：不承认，不等于不存在；不存在于账面的力量，最后会从账面外把你接管。

行动触发，给两个具体的：下次去日本旅行，看神社先看它的"分工"（求什么的人来这里），伊势管皇统、稻荷管生意、天神管考试，一张神社地图就是一张古代社会的需求清单。读任何历史书时可以借用迪尔的镜头纪律：数一数全书给了统治阶层多少页、给了其他人多少页，页数的分配本身就是一种史观。

#### 事实边界

本篇依据商务印书馆中译本的扫描版文本写成，原文 OCR 噪声较重，专名已尽量回正。断代采用本书口径（中世 1185–1615，近世 1615–1868），不同学者另有分法。农民占比八成到八成半、六万三千个村庄、室町近七成税率、贱民约三十八万、御家人约两千、《五轮书》约 1643 年、《叶隐》1716 年、伊势二十年式年迁宫，均出自原书，属手册类约数；东海道里程与驿站数为英文原书口径。第四层"幕府不敢改税基"的归因、第三层三根线的提法是我的读法，作者本人只陈列现象并以"具有讽刺意味的是"点题，未做此论断。
