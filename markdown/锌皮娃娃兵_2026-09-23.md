# 锌皮娃娃兵

# 先把这本书讲一遍

一九八三年深冬的一个阴冷深夜，在白俄罗斯明斯克郊外一座破旧的火车站货运站台边缘，一列从苏联中亚边境开来的军用闷罐火车在刺耳的刹车声中缓缓停下。几名身穿厚重棉大衣、神情冷漠麻木的内务部内卫士兵，在手电筒惨白光束的照射下，从车厢深处缓缓抬出一具具沉重冰冷的铅灰色金属长箱。在这些长箱的外皮上，用白漆简陋地喷涂着死者姓名、出生年月与入伍番号，箱体四周被坚硬的锌铁皮用粗大的工业焊条严密焊死，散发着刺鼻的金属与防腐化学药剂气味。站台阴暗的风雪角落里，一位头发花白、身穿破旧羊毛披肩的母亲突然发出了撕心裂肺的凄厉嚎哭，发疯般扑向那具冰冷的棺木，用流血的十指拼命抓挠着坚硬的锌铁皮，哀求看守士兵用铁锤将棺木撬开一条缝隙，让她最后看一眼自己年仅十九岁儿子的面庞。然而军官面无表情地挡在她身前，冷冰冰地出示了国防部最高保密指令，严禁任何家属擅自开启锌皮棺材，必须在国家安全机关克格勃人员的严密监督下连夜秘密下葬。白俄罗斯作家斯维特兰娜·阿列克谢耶维奇在这部震惊世界的口述史史诗《锌皮娃娃兵》中，以近乎泣血的文学勇气，揭开了冷战晚期红色超级大国最隐秘、最残忍的一道道德溃烂脓疮。在长达十年的阿富汗战争中，数十万连胡须都未长齐的苏联稚嫩青年，在宏大帝国主义宣传的欺骗下被送往异国他乡充当战争绞肉机的血肉耗材，最终换来的只有这具具冰冷封死的金属盒子。｜装在密封锌皮棺材里无声运回故土的年轻士兵遗体｜，成为敲响庞大帝国丧钟最沉痛的无声丧钟。

### 明斯克午夜站台锌皮棺材与战地母亲的绝望抓挠

为了彻底讲透这场让整整一代苏联青年沦为历史牺牲品的荒诞战争，全书的第一条叙事主线聚焦于那些原本天真烂漫的普通青年是如何被送上兴都库什山脉血火战场的。一九七九年十二月末，克里姆林宫内部几位垂垂老矣的政治局巨头在极度黑箱保密的状态下做出了武装入侵阿富汗的冒险决断。为了动员全社会的年轻人入伍，苏联国家宣传机器开动了全部马力。共青团报纸、国家电视台与广播电台日夜不停地播放着宏伟的革命军乐，将这场野蛮的军事侵略粉饰为支援南部友好邻邦抵御美帝国主义侵略的崇高国际主义援助。在学校礼堂与征兵办公室里，那些从小在卫国战争英雄神话熏陶下长大的单纯中学生们热血沸腾，纷纷在申请书上按下鲜红的手印自愿报名参军，坚信自己是在沿着父辈打败法西斯的伟大足迹去解放受苦受难的阿富汗人民。然而当这群稚嫩的娃娃兵乘坐伊尔重型运输机降落在喀布尔机场的那一刻，残酷的现实瞬间给了他们灭顶之灾。迎接他们的根本不是手捧鲜花热烈欢迎的阿富汗兄弟，而是呼啸而来的火箭弹、无处不在的狙击冷枪，以及当地老百姓眼中那刻骨铭心的仇恨与怒火。

### 共青团国际主义神话动员与中学生志愿入伍的狂热

在阿富汗那片被烈日烤焦的荒蛮戈壁与幽深峡谷中，苏联士兵们经历了一场在身心层面被彻底非人化的残酷精神异化炼狱。面对神出鬼没、化整为零的阿富汗圣战游击队，苏联引以为傲的装甲洪流与喷气式轰炸机在崇山峻岭中失去了全部优势。游击队员们利用熟悉的地形设下无数致命的塑料地雷与步兵拌雷，数以万计的苏联年轻士兵在巡逻途中被炸断双腿、下体撕裂，在烈日下痛苦哀号直至失血休克。为了报复战友被俘后遭遇的割鼻、挖眼与扒皮等极其野蛮的虐杀，苏军部队内部迅速滋生了疯狂的嗜血复仇心理。整座整座的阿富汗村庄在重炮覆盖下被夷为平地，无辜的妇孺老幼在清剿行动中被无差别扫射。阿列克谢耶维奇在书中记录了多位士兵的令人毛骨悚然的忏悔，在战场上他们学会了像踩死蚂蚁一样毫无感觉地扣动扳机射杀平民，学会了从死尸身上抢夺牛仔裤、卡带录音机和金首饰用于走私换取烈酒与毒品。军纪彻底荡然无存，老兵对新兵施加着令人发指的毒打与性虐待。这场战争像一台巨大的精神绞肉机，彻底剥夺了这些十九岁孩子身上最后一丝关于人性的善良与羞耻感。｜阿富汗荒原血火战场对普通苏联青年的残酷精神异化｜，展现了国家暴力对人类灵魂最极端的摧残。

### 兴都库什山脉残酷游击战与普通青年的精神非人化

全书最为动人心魄也最令人窒息的篇章，属于那些在后方苦苦守候却最终等来噩耗的战地母亲、妻子与军医护士。阿列克谢耶维奇用录音机忠实记录下了数十位受害者亲属毫无修饰的泣血口述。一位年轻的战地女护士回忆，在喀布尔野战医院那座四处滴血的搭盖帐篷里，她每天要处理数十个被烧成焦炭或截断四肢的年轻躯体，由于缺乏麻醉药与血液制品，年轻的伤员只能在剧烈抽搐中死死咬住毛巾，嘴里用微弱的气息喊着妈妈。而在苏联本土，母亲们在收到阵亡通知书的同时，被当地党委和克格勃官员严厉警告，不准在墓碑上刻下死于阿富汗的真实字样，只能含糊地写下在服兵役期间因病牺牲，严禁在葬礼上发表任何质疑战争性质的言论。面对装在锌皮棺材里被严重损坏、甚至只剩下几块烧焦骨殖的儿子遗体，母亲们的精神防线彻底粉碎。她们愤怒地将国家颁发的红星勋章砸在官僚桌上，痛斥所谓伟大的祖国用谎言杀死了自己的孩子。阿列克谢耶维奇以极其锋利的手术刀笔触指出，正是母亲们那一声声撕裂长空的绝望嚎哭，彻底剥下了苏联官方宣扬了数十年的爱国主义宏大叙事面具。｜官方英雄主义虚伪神话被战地母亲血泪彻底粉碎｜，露出了极权体制将平民生命视为草芥的冷酷本相。

### 地雷残肢截肢手术与年轻女护士的良心煎熬

在喀布尔那些由简易帆布搭盖的野战医院里，女医护人员们经历着另一场同样血腥的人性噩梦。每天清晨随着直升机的轰鸣降落，担架员抬下来的是一个个浑身血肉模糊、在塑料地雷爆炸中失去双腿的年轻战士。许多士兵在被抬上手术台时甚至还保持着清醒，他们死死抓住护士的双手，带着哭腔哀求医生保住自己的双腿，因为他们知道在战后的苏联社会，一个失去双腿的残疾人将意味着终身生不如死的绝境。然而为了挽救生命，外科医生们不得不戴着沾满鲜血的橡胶手套，用冰冷的骨锯切断一根根稚嫩的腿骨。在连续工作四十多个小时的极度疲劳中，护士们每天要将成桶被截下的断肢抬到营区外深埋。一位年轻护士在录音中哭诉，她一生中最可怕的噩梦就是那些被截下的腿，上面还穿着崭新的军靴，脚趾甚至还在神经反射中微微抽动。这种日复一日面对生命被残暴肢解的场景，让无数战地女护士在回国后患上了严重的精神抑郁与终身失眠，她们用一生的眼泪为帝国的战争罪孽承担着无辜的苦难十字架。

### 喀布尔野战医院伤兵惨象与白发母亲退回国家勋章

全书后半段以近乎残酷的冷峻，追踪了那些侥幸生还回到故土的伤残退伍老兵在战后的悲惨命运。一九八九年二月十五日，最后一批苏军装甲部队在格罗莫夫将军率领下撤过阿姆河友谊大桥，长达十年的阿富汗战争以苏联的彻底军事溃败仓皇收场。然而踏上祖国土地的十五万退伍军人，并未迎来他们想象中的鲜花与英雄礼遇。随着戈尔巴乔夫公开化改革的推进与全社会对阿富汗战争罪恶真相的反思，整个苏联社会对这些老兵的态度瞬间从敬佩反转为冷漠、避之不及乃至公开唾弃。当残废的退伍老兵摇着轮椅去政府民政部门申请微薄的伤残抚恤金与配装假肢时，官僚们面无表情地抛出了一句在老兵心中回荡了数十年的诛心之言，我们又没有派你到阿富汗去。这群深陷创伤后应激障碍PTSD折磨的退伍军人，患有严重的失眠、幻听与暴力狂躁，许多人在贫困与歧视中染上酗酒、吸毒，甚至沦为了苏联解体前夕各大黑帮争相雇佣的冷血职业杀手。阿列克谢耶维奇在全书尾声深情叹息，这群被国家机器骗上战场、又被国家机器像垃圾一样随手抛弃的锌皮娃娃兵，是整个苏联极权体制走向崩溃过程中最沉痛的殉葬品。

# 作者凭什么这么说

斯维特兰娜·阿列克谢耶维奇在《锌皮娃娃兵》中之所以能够写出具有摧枯拉朽般道德震撼力与历史穿透力的旷世巨作，关键在于作者彻底打破了传统军事历史学对将军作战地图、外交公报与战役统计数据的狭隘垄断，开创了一种以复调音乐般的普通人声音记录时代精神巨变的口述史写作范式。全书的论述并非建立在虚构的小说家想象之上，而是扎根在三组极其扎实且冒着巨大政治风险搜集的历史证据网络之中。

### 第一项证据，历时数年五百余位阿富汗战争亲历者的原始采访录音带

全书最为坚实也最无可替代的核心证据，是阿列克谢耶维奇自上世纪八十年代中期开始，历时数年走遍莫斯科、列宁格勒、明斯克、基辅、塔什干等全苏各大城市与偏远村庄，对超过五百位阿富汗战争老兵、战地护士、空姐、母亲与遗孀所展开的超高密度深度口述访谈录音带。作为一名受过严格新闻训练的严肃调查作家，作者坚持带着一台笨重的磁带录音机深入当事人的私人起居室。在采访中，作者拒绝记录那些在官方聚会上经常使用的套话空话，而是以极其耐心的女性悲悯，引导被访者回忆战场上最深层的生理感官记忆。例如在回忆伤兵急救时，战地护士详尽描述了被烧焦的人肉在帐篷里散发出的甜腻恶臭，以及士兵在临死前如何像婴儿一样哭喊着要吃苹果的细节。这些微观而充满痛感的生命记忆，彻底排除了战争回忆录中常见的事后合理化修饰，为全书提供了坚不可摧的生理学与心理学实证支柱。阿列克谢耶维奇还特别注意搜集并抢救士兵在战壕中写下的原始日记与未寄出的家书草稿。这些写在发黄的香烟包装纸或皱巴巴信笺上的文字，没有任何宏大的政治辞令，充斥着对母亲做的苹果馅饼的渴望、对死亡的巨大恐惧以及对战友惨死身旁的痛苦记录。作者通过将这些战场绝笔与国防部官方公布的英雄烈士事迹进行逐字比对，用不可辩驳的微观心理实证，揭露了官方宣传是如何残暴地篡改了前线战士最真实的生命遗言。

### 第二项证据，苏联国防部战地审查文件与克格勃对阿战言论绝密监控通报

第二项硬核证据深入到了苏联极权国家安全机器封锁战争真相的制度档案。在全书出版后引发的剧烈政治震荡中，苏联军方与退伍军人保守组织曾对阿列克谢耶维奇提起了长达数年的名誉侵权恶意诉讼。在庭审与随后的档案解密中，大量的官方保密规程被推向了司法前台。档案证实，苏联国防部战地政治总督察部曾对从阿富汗寄回本土的所有军人信件实行百分之百的严格预先审查，凡提及士兵阵亡、截肢、游击队伏击或反战情绪的信件一律被黑墨水涂黑或直接扣押销毁；内务部与克格勃严密监控各地公墓，严禁母亲在死者墓碑上刻写阵亡字样。作者通过在法庭上将这些官方保密规章与老兵口述当面对质，雄辩地证实了国家机器在长达十年的时间里，是如何通过制度性的系统性谎言欺骗了两亿苏联人民，为全书注入了冰冷坚硬的法理学实证骨骼。

### 第三项证据，明斯克法庭审判速记实录与原告老兵当庭良心反转档案

第三组证据构成了全书最震撼人心的人类道德法庭文献。在全书中文版附录中完整收录的一九九二至一九九三年白俄罗斯明斯克地方法院审判速记记录中，军方操纵的保守派原告起诉作者丑化苏军形象、亵渎国际主义英雄荣誉。然而在长达数月的公开庭审中，发生了令全场肃然起敬的历史性良心逆转。多位最初被军方蒙蔽参与起诉的老兵和母亲，在法庭上当面听到作者播放的原始录音带中自己泣不成声的真实讲述时，内心的良知被彻底唤醒。一位母亲在法庭上失声痛哭，当庭撤回起诉，并站起身紧紧拥抱被告席上的阿列克谢耶维奇，公开坦承自己此前的起诉是被军官利用了痛苦，作者书中所写的一切正是自己死去的儿子用鲜血换来的真实真相。这批司法审判速记文献，成为了人类文明史上罕见的文学战胜国家谎言的庄严道德证书。

### 一条作者没有明说却必须成立的前提与分析失效边界

在阿列克谢耶维奇宏大深沉的悲悯人道主义叙事背后，潜藏着一条作者未曾彻底挑明却构成全书底层推论基石的核心假设，那就是个体的痛苦与生命的尊严，永远拥有高于任何国家地缘战略诉求与政治意识形态的神圣至高性。全书以绝对和平主义的人道准则，对一切形式的战争动员实施了彻底的道德宣判。然而这种绝对人道主义视角的失效边界同样存在，当一个文明体遭遇毫无妥协余地的法西斯侵略、灭顶之灾或野蛮屠杀时，如果全盘采取拒绝一切武力反抗的绝对和平主义立场，个体的生命尊严往往会在侵略者的屠刀面前遭遇更彻底的毁灭。阿富汗战争的不义性质使得绝对人道主义在本书中具备无可争议的道德正当性，但在面对具有反侵略与正义自卫性质的卫国战争时，战争中的牺牲就无法被简单还原为被欺骗的受害者逻辑，必须引入更为复杂的正义战争论与政治共同体防卫伦理加以综合审视。

# 真正在起作用的几件事

剥离苏联官方长达十年的爱国主义狂热宣传与冷战地缘博弈的宏大辞令，真正驱动数十万苏联青年走向阿富汗绞肉机并最终引爆红色帝国解体的，实际上是四台动力学原理截然不同却高度咬合的体制动力学齿轮。这四台齿轮在苏维埃官僚极权体制的机体内部高速运转，共同酿成了这场旷世的人间浩劫。

### 第一台齿轮，老年政治集团地缘偏执与黑箱盲动齿轮

### 事实边界

一九七九年十二月二十五日苏联正式出兵阿富汗，在长达十年的武装占领与战争中，苏联累计动员超过六十二万人次参战，官方公布阵亡人数为一万四千四百五十三人，伤残人数超过五万人，战后阿富汗老兵自杀与精神创伤率位居全苏历次战役之首。

全书在苏联晚期一九八九年首次公开发表时引发轩然大波，白俄罗斯退伍军人保守组织在军方支持下对作者提起名誉侵权诉讼，指控其诋毁苏联军队国际主义荣誉，经过长达数年的庭审辩论与受害母亲的当庭良心声援，法庭最终驳回了原告的全部诉求。

苏联军方在战争期间对士兵阵亡信息实行极其严酷的保密控制，锌皮棺材由专职护送军官直接押送至死者家乡公墓，严禁开棺并强制在夜间举行秘密葬礼，死者墓碑上严禁出现死于阿富汗字样，直至一九八九年大撤军后真相才全面向苏联社会公开。

作者阿列克谢耶维奇因开创复调纪实写作、记录我们时代苦难与勇气的庄严纪念，于二〇一五年荣获诺贝尔文学奖，《锌皮娃娃兵》被国际文学界公认为世界反战非虚构文学史上与《西线无战事》比肩的传世巅峰丰碑。
