# 怎样观察一棵树

一个清晨，作者的丈夫约翰跑来报告：院子里的栎果发芽了。就是壳斗底下鼓出一点胚根的那种小事。她听了很高兴，高兴的不是芽，是丈夫。这个原本对树无感的人，被她传染了。全书就从这个小场景开进去。

胡格是花艺师出身的博物学作家，摄影师卢埃林原来是工程师。写这本书之前，他们俩干过一件事：花四年、跑两万英里，把弗吉尼亚州最美的树拍了个遍。拍完那些冠军树、名木古树，两人转身写了这本方向完全相反的书：不看名树，看家门口的普通树；不看整棵，看局部；不满足于认名字，要看过程。书里深写了十种树，全是北美街头巷尾的常见货色：水青冈、悬铃木、黑胡桃、圆柏、银杏、红花槭、荷花玉兰、紫荆、乔松。选树标准里明写着一条：常见，而非不常见。

全书三部分。第一部分辨"观树"与"看树"的区别，给一套人人可用的观察策略；第二部分按部件走，叶、花、果、芽、叶痕、树皮，每样教你看什么；第三部分给那十种树各立一章肖像，把方法落到具体的树上。尾声里，两人在一家汉堡王后面的停车场做了一次树木调查，那一段留到后面细讲。

### 书里最好看的那些瞬间

柿子花事件。一个夏天的清晨，她在河边捡到一个怪东西，毛茸茸的绿色四角星，"像一个微型的 UFO"。她把它弄丢了，惦记了一个礼拜，最后循着记忆里的树皮纹路找回那棵树，判明那是柿子树的败育雌花。为一个捡来的小绿疙瘩，她顺藤摸瓜研究了柿子的雌雄异株。

银杏的传粉滴。她从几英里外的朋友家剪回一根雌银杏枝，插在厨房窗台上。两周后的一天，她洗着碗一抬头，看见胚珠上顶着两颗晶莹发亮的小液滴。那是传粉滴，银杏准备好接收花粉的信号。她写自己"欣喜若狂"，每次看它都想到"期待"这个词，因为它"精心准备好了迎接永远不会到来的花粉"。窗台上的孤枝，等不来那阵风。

水青冈的凋存叶。这种树的老叶不按时落，枯成褪色的金色还挂在枝头，"像挂在晾衣绳上的袜子"，一直挂到来年早春，变成半透明。还有她给秋天的玩法：抓住一片正飘落的叶子算一个月的幸福，她每年秋天要去抓十二片，"做起来比想象中难"。

黑胡桃的叶痕。叶子掉落后枝上留下的疤，黑胡桃的像压扁的三叶草，三对维管束痕排成马蹄形，她在里面认出了外星人 E.T. 的脸。北美柿的树皮裂成小方块，她看着想起锅里切好的布朗尼冷却时彼此分开的样子，方块之间的沟壑是肉桂色。

读这些段落你会发现，她的本事不在植物学知识，在比喻的准头：袜子、布朗尼、E.T. 的脸，全是厨房和客厅里随手的东西，可每个都严丝合缝，你看过一眼就再也忘不掉那棵树的样子。

### 这本书在说什么

表面上是教你认树的部件，往深一层，它在反对一种我们都没察觉的观看方式。书里有个说法叫"单镜头问题"：我们看树永远只用广角镜头，一眼扫过去，"一团树叶长在树干上"，认出是棵什么树，就算看完了。胡格要换的是特写镜头：盯住一个芽、一片叶痕、一块树皮，看它一天天变化。用她的话说，树看着纹丝不动，像纪念碑一样震撼却缺乏生气；只有盯住比树干长得快的部位（芽、花、果），你才会脱口而出那句"这是活的！"。原书名 Seeing Trees，看见树。大多数人不缺看，缺看见。

结论：差在镜头。看树用广角，认个整体；观树用特写，盯一个部件看它的变化。

怎么想到的：认出"这是棵银杏"只是给已知的东西贴标签，信息量是零。真正的戏都在局部：芽在膨大，花在分泌传粉滴，叶痕里长着一张脸。树生长得慢，肉眼抓不住，可芽、花、果比树干长得快，盯住它们，静止的纪念碑就变成了正在发生的过程。她丈夫被传染的起点，就是一颗栎果的胚根。

常见坑：以为要先背下一堆植物学术语才开始。顺序反了，先看，看得心痒了，术语自己会来找你。

结论：不用。一天一小时，一棵行道树就够，普通树比珍稀树更值得看。

怎么想到的：她挑的十种树全是北美路边货，选树标准明写"常见而非不常见"。道理有两层。近处的树才看得了"过程"，名木古树你一年见一回，只能拍照，不能相处。还有一层更深：珍稀树的好是公认的，用不着你；把一棵杂树看成奇迹，那才是你自己的眼睛。书里说北美枫香"从杂树摇身一变成为自然奇迹"，树没变，变的是看的人。

常见坑：把观树当成一次性的春游项目。它是日课，得天天做。

结论：向下看。地上散落的不是垃圾，是树寄给你的信。

怎么想到的：她拒绝用"树木残渣"这个词。老叶、空果壳、花条、种子，是"散落的树木的信息"，每一样都标着一个时间事件：这棵树开过花了，结过果了，换叶了。高处够不着的叶和果，风替你摘下来送到脚边，弯腰就是。她顺便批评了一种流行的园艺观：专门培育不结果球的枫香、不长翅果的槭树，图个"整洁"。把树收拾干净了，等于把信撕了。

常见坑：只抬头不低头。大多数人脖子仰酸了，错过了脚底下八成的材料。

结论：三样足够：放大镜、双筒望远镜、平板扫描仪。都不贵，贵的是养成用的习惯。

怎么想到的：放大镜看绒毛和气孔，双筒看高处的花和果。她借来一台双筒，从大学科学楼三楼的窗口第一次"洁净地"看清了松树顶的雌球花。扫描仪是她的独门用法：把叶子和花压平扫描，连日期一起打印存档，就是一份自己的物候档案。卢埃林有句话配在这里正好："拿起相机，你才能真正看清事物。"工具不只是记录用的，它让肉眼够不到的世界进入视野。

常见坑：以为肉眼足够。肉眼当然够开始，但看不见传粉滴上的光。

结论：以年计。观树的终极乐趣在物候：同一棵树的一年四季、十年枯荣。

怎么想到的：花变成果要经历一长串阶段，"不是某个神奇瞬间变成的"。看一次得到的是照片，看一年得到的是电影。书里举了个让人肃然起敬的例子：简·康毕斯坚持记了六十年的物候记录，后来被科学家拿去做了气候变化研究。一个普通人的慢观察，攒够年头就成了科学数据。

常见坑：期待一次看全。一次看全的是明信片。

结论：叫不出名字不妨碍看。命名是顺带的事，不是入场券。

怎么想到的：书里专门讨论了"给不给树命名"这件事，态度很松：名字有用，但把命名当终点，就成了收集标签。认不出的时候可以找向导：博物学家、树艺师、护林员，互联网也算"新邻居"。她自己最信的是另一条："最有助于理解树的三件事：接触、接触、再接触。"她为观察栎树上的昆虫，在树下架了双筒望远镜和吊床，自己盯着看，不去问专家，"通过自己的观察来解决问题，更有满足感"。

常见坑：查不到名字就放弃。名字是树的户口，你看的是树的日子。

一句话：**这本书教的是把"看见"从本能练成本事。**

```
看（本能）                看见（本事）
   ─────────               ─────────
   广角·整体·认出名字  →   特写·部件·追踪过程
   远方的名树          →   门口的杂树
   一次看到            →   看上一年
```

第一层提到，这本书的尾声发生在一家汉堡王后面的停车场。

一个写了半辈子自然书、拍过两万英里名木的作家，和她那位工程师出身的摄影师搭档，把全书最后一场树木调查放在了快餐店后面：加油站招牌底下的一棵北美乔松，开着花的稠李，挂着去年果荚的合欢。没有森林，没有保护区，没有"值得一去"的目的地，就是美国公路边最司空见惯的一块废地。两个人在那里观察得有滋有味，然后把这段经历写进了书的结尾。

这个结尾是整本书的题眼。前面几百页教方法：特写镜头、向下看、借助工具、追踪物候。停车场这一幕回答的是一个更前面的问题：值得吗？为这些不起眼的树，花这么多眼神，值得吗？她用行动回答：值得，因为值不值得从来不取决于树，取决于看的人有没有把眼睛调好。停车场这一幕没有降低方法的规格，恰恰是把方法用到了底：如果这套看法在汉堡王后面都成立，那它在任何地方都成立；反过来，一套需要特定目的地才能成立的"爱好"，那是消费，不是观看。

她在书里引了奥威尔的一句话压阵：看清眼前之物，需要不断努力。这句话值得停一下。我们默认"看见"是不费力的事，睁着眼不就在看吗？奥威尔说不是，看清眼前之物恰恰最难，因为眼前的东西被"熟悉"包裹住了，熟悉是眼睛的麻药。名树能击穿这层麻药，靠的是稀奇；而胡格这套方法，是教你不靠稀奇也击穿它。这是两种完全不同的观看立场：一种永远在寻找值得看的对象，一种致力于成为看得见的人。跟喝汤一个道理：名贵馆子的汤好喝，功劳在汤不在舌头；能从家门口那碗汤里喝出火候的，才是自己的舌头。前一种能力跟着钱包走，后一种跟着人走。

我攻一下这个结论：这是不是把"降低期待"包装成了境界？毕竟，看名树、去远方，也是真实的热爱，凭什么停车场就更高明？攻到一半我发现答案藏在她的故事里：她是看完了两万英里名树之后，才回到停车场的。顺序不能反。先有足够的阅历知道"稀奇"长什么样，再回到日常还看得见，这个"回得来"才是功夫；没出过门就把楼下当全世界，那是另一回事。她的高明不在停车场，在去了远方之后，停车场对她依然成立。

所以这本书最后教的是一种和世界相处的方式：把"去哪里看"的问题，换成"怎么在看"的问题。前者永远受限于钱包、假期和运气，后者只受限于你自己。书里有句话可以作证：她在任何一个不熟悉的地方，只要能认出一棵黑胡桃，"就会觉得这个地方不再陌生"。练出这双眼睛的人，走到哪里都自带熟人。这个回报，比认出十个树种大得多。

胡格写这本书的那股劲儿，说穿了是一种温柔的着急：人跟自然住在同一个院子里，却越来越像陌生人。她不开环保课，不列濒危名单，她走的路数是把陌生人重新介绍给你认识。你看，这是黑胡桃，你闻一闻它的叶子，柑橘味；以后在火车站一样的人群里，你一眼就能把它挑出来。她相信认识先于爱护，人对叫不出名字的东西是狠得下心的。

盲点也得说。第一，这本书的树全是北美的种，中国读者认树时对不上号，方法能搬，树种不能搬，这是翻译引进时没解决的事。第二，她的世界太干净了。观察、记录、感染家人，书里几乎没有"看不下去"的时刻，可真实的人开始一件慢事，九成败在前两周的枯燥期，她对这段劝退期着墨太少，把习惯养成说得太容易了。第三是我个人的保留：全书几乎不碰科学结论，物候、传粉、蒸腾都点到即止，读者会以为"观察"止于欣赏；其实只要她再迈半步——比如讲清康毕斯那六十年记录是怎么变成气候证据的，读者就能看见个人观察和科学之间的桥。

跨着领域看，这套方法跟读人是一个道理。认识一个人也有两种镜头：广角是标签，职业、收入、哪个学校毕业的，一眼扫过就算"认识了"；特写是看他怎么处理一件小事，怎么对待服务员，怎么过一个普通的下午。档案袋装的是广角信息，日子过出来的是特写信息。我们抱怨"看不懂一个人"，多半是广角用得太多，特写一次没用过。

行动触发，给两个立刻能做的：今晚下班路上，挑一棵你天天路过但从没正眼瞧过的树，站住看三分钟，只看一个部位：树皮、叶子或者树底下散的东西，明天同一时间再看一次。做内容的人还可以偷她一招：她的每个比喻都从厨房和客厅里取（晾衣绳上的袜子、锅里的布朗尼），写专业内容时，比喻的取材半径决定了读者跟你的距离。

#### 事实边界

本篇依据商务印书馆中译本的扫描版文本写成，原文 OCR 噪声较重，树种名已按书后中外词汇对照表尽量回正。柿子花、银杏传粉滴、凋存叶、黑胡桃叶痕、布朗尼树皮、抓落叶等细节均出自原书；"四年两万英里拍名树""简·康毕斯六十年物候记录用于气候研究""梭罗爬树摘球果"亦出自原书转述。第四层关于停车场尾声的读法、第五层对"习惯养成着墨太少"的批评是我的判断，非作者自述。
