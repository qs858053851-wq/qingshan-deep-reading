ISSUE NOTE // 01 为什么是十分钟？

我不是想把一本书缩短，只是想先认出它的骨架。

面对一本厚重大书，我常常不知道该不该交出一周的时间。封面和推荐语习惯把每本书都说得无比重要，可人的生命与精力终归有限，真正值得慢读的书，只能靠自己去辨认。

所以我先做一次足够扎实的深读：拆解它的核心问题、论证链条、制度逻辑与时代盲点。十分钟读完这份长解读，不等于读完原书；它只是帮我们诚实地作出下一步选择：带着一个更清晰的问题回到原著，还是坦然放下它。

书读得多了，这些冷峻的骨架与火花不该只留给自己。于是把它们整齐码放出来，给同样站在书架前犹豫的人。

EDITORIAL PLEDGE // 读者公约

关于这些解读，我想诚实三件事

一、它不是原书

长解读是一扇推开的门，不是绕过原著的捷径。最好的结果，是让你带着一个更刁钻、更有力的问题回到原书本身。

二、它不是定论

这里记录的是具体的证据链、权力逻辑、制度代价与个人的审视偏爱。今天确信的判断，明天仍可能因新材料而深刻改写。

三、人与工具的诚实分工

机器协助拉平海量文献与检索材料；选什么书、追问什么本质、保留哪些锋芒与落笔的全部责任，始终归于青山。
