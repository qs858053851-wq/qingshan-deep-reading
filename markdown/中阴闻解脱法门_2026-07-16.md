# 中阴闻解脱法门

先把书名拆开。藏文原名"巴多脱卓"：巴多（Bardo）意思是"中阴"，指人死后到再投生之间的那段过渡地带；脱卓意思是"闻度"，靠听闻而得度。合起来，这是一部在人临死和死后念给他听的经：藏传佛教认为，人死后的四十九天里，神识（相当于我们说的灵魂，佛教不用这个词）还在、还听得见，此时在遗体旁按日程念诵这部法，一步一步告诉亡者"你现在看见的是什么、该怎么办"，亡者只要听懂了、照做了，就能当场解脱，不再进入投生的轮回。说白了：这是一份死后世界的导航手册，逐日播报路况。

它的流传路线本身就是个故事：托名莲花生大士（八世纪把佛教带进西藏的祖师）所传，在藏地作为伏藏经典世代由喇嘛口耳持诵；上世纪二十年代由锡金的达瓦桑杜喇嘛译成英文、美国学者伊文思-温慈整理后在牛津出版，轰动西方，得名《西藏度亡经》（The Tibetan Book of the Dead）；1936 年，中国居士张莲菩提再从英文本转译回中文。一部藏地密法，绕道英国才回到汉地。本书正是这个译本，前面缀着释超一、蒋维乔等八篇民国佛教界人士的序。

### 死后四十九天的完整日程

全书的主体，是把死后历程分成三步、逐日给出"作法"。跟着走一遍。

人快断气时，念诵者凑近他耳边（但不要贴上）反复叮咛：你的气息就要停了，接下来会出现"根本净光"，一片如无云晴空般的光明。那就是实相本身，你的心和它本来是一个东西，认出它、融进去，当下解脱，根本不用进中阴。书里连生理细节都给了：断气前后有二三十分钟的窗口期，要在"灵力"降过心口、还没继续下坠之前完成提醒；死者若昏昏欲睡，要轻呼其名、用指尖轻按他喉侧的脉管。错过第一次净光，死后约一顿饭工夫还有第二次，但这时业力开始起障碍，光就没那么容易认了。

没认出净光的亡者，先昏迷三天半到四天。醒来的第一个念头是："出什么事了？"他看得见哭泣的亲属，跟他们说话却没人理会，书里写他"懊丧莫可名状"。这时念诵者告诉他：你已经死了，所有人都会走到这一步，不要贪恋，往下听。

接下来七天，每天有一位佛现前。第一日毗卢遮那佛放蓝光，第二日金刚萨埵放白光，第三日宝生佛放黄光，第四日阿弥陀佛放红光，第五日不空成就佛放绿光，第六日五方佛齐现，第七日持明诸尊现前。每一天的结构一模一样，是全书最精巧的设计：佛的智慧之光强烈刺眼、"灿烂眩耀，莫敢仰视"；同时旁边总伴着另一道柔和暗淡的光：天道的微白、人道的淡黄、地狱道的烟雾色。亡者因为业力，会本能地害怕那道强光、亲近那道舒服的弱光。而念诵者每天喊的都是同一句话：不要怕强光，那是来接你的；不要贪恋弱光，那是六道轮回的入口。**刺眼的那道才是出路，舒服的那道通向的是又一轮生死。**每天一次机会，认出即度。

七次都没认出来的，进入更可怕的一周。饮血忿怒尊登场：三面六臂、九目圆睁、獠牙外露、颅骨为饰、饮血持刀，吼声千倍于雷。但书里说得明白：这五十八位恐怖之神，就是前七天那些慈悲之佛的"变化身"：同一批佛，换了一副脸。为什么换脸？因为温和的接引你不理，只好用吓的。而给亡者的指令仍然只有一条，且每天逐字重复：此相由你自己的心识变现，认出它，"即得俱时解脱"。书里打了个比方：狮子皮，知道是空皮的人一眼看破，不知道的人吓得魂飞魄散。皮没变，知不知道的差别而已。这句"皆汝自识所变现"在这一段像钟摆一样反复响，它到底意味着什么，按下不表，本篇最后再算这笔账。

两周的接引全部错过，亡者坠入最后一段"悉罢中阴"，即求生中阴。此时他获得一具"意生身"：无形无质，穿墙过山无所阻碍，一念之间飞到任何想去的地方，感官比生前敏锐，记忆力九倍于生时。听着像超能力，实际是失重的恐慌：业风从背后卷来，身不由己如风中羽毛；他回家看见亲人分他的遗物、哭他的丧，喊话没人应，"如红热锅中被炸之鱼"。若生前多作恶，还会看见夜叉追杀、猛兽追逐、山崩海啸，被逼到白黑红三座悬崖边。书里点破，那三座悬崖不是别的，是他自己的贪、嗔、痴。

接着是冥判：司善之神用白石子数他一生的善行，司恶之神用黑石子数他的恶行。亡者吓得发抖，撒谎说"我没干过"，司命鬼王举起业镜：生平善恶，纤毫毕现，谎言当场作废。狱卒上来断头、刳心、抽肠，但他痛而不死，身体碎了又复原，反复受刑。就在这最恐怖的一幕里，经文给出全书最大胆的一句导示：连这个法庭都是你心识的投影，"空能坏空，无有是理"——你的身体本来就是空的，空砍不坏空，怕什么？

连冥判都没能让他醒悟的，只剩最后一件事：投胎在即。经文先教"闭胎门"，五步观法，一步不成再退一步，其中最惊人的一步：亡者会看见未来父母交合的景象，若对母亲生爱、对父亲生憎，就投男胎；反之投女胎。一念的爱憎，当场决定了下一辈子。所以要在那一刻认出这景象也是幻，胎门自闭。实在闭不住，最后教"择胎"：六道各有征兆（见天宫可入，见岩穴是畜生道，见枯草荒漠是饿鬼道，闻悲切歌声千万止步（那是地狱），挑个能听闻佛法的人身，发愿投一个好人家。手册的最后一页，是教你怎么输得体面一点。

整个结构像一场层层降级的营救：最好命终当下解脱（法身），次好在光明现前时解脱（报身），再次投生善道来世再修（化身）。四十九天，每一天都有一根绳子垂下来，每一根都写着同一句话。而全书结尾对活人说：这部法要在生前"读诵之、每诵三遍、牢记于心"。这句话很奇怪，度亡的经为什么要活人熟读？也按下不表。

一部描述死后世界的书，谈不上考古学意义的证据，但它有自己的论证地基，而且这个地基相当清楚。整套体系立在一个总前提上："三界唯心，万法唯识"，你经验到的一切，包括死后经验到的一切，都是心识的显现。序文里张树铭一句话点破：全书"其理则一准诸唯识"，中阴的种种奇景"仍属唯识上事"。接受这个前提，全书的逻辑就顺了：既然佛与鬼都是心的投影，那么改变认知就能改变遭遇，一句在耳边说对的话，确实可能在关键一刹那扭转亡者的去向，这就是"闻即得度"的原理。不接受这个前提，全书就只是一份精美的神话地图。它的可信度不靠实验，靠你在哪个哲学立场上站着。

书里给出的经验性支撑有三个。其一，修行者的现观：重译述缘里说，藏地有成就的喇嘛"以定力验得七七中阴境界，而后愈努力于本法之宏扬"，即禅定中亲见中阴景象，与经文所述相符。其二，教义谱系的支撑：中阴之说并非藏密独造，汉译《俱舍论》《瑜伽师地论》里早有"中有"的系统论述（蒋维乔序里引《俱舍论》：中阴身如五六岁小儿，能远远看见来世父母），此书只是把显教理论变成了可操作的仪轨。其三，果上的迹象：书中说修持此法者火化时有圆光、骨相等瑞相。这三条里，第二条是扎实的文献事实，第一、三条对局外人而言只能存而不论：定中所见无法他证，瑞相之说无法核验。

书里没明说、但整套作法必须成立的隐形前提还有三个：死后神识存续四十九天且听得懂人话；活人的声音能够传到中阴（哪怕尸体不在场，念诵时"作观召请"也有效）；以及最关键的一条：认知在死后瞬间可以改写业力的走向，"心念一生，业用即必随之"。这三条哪一条塌了，仪轨就只剩安慰在场亲属的功能。

边界条件，书自己划得很诚实：大圆满、大手印修到家的人"无须乎此法"，命终当下自解脱；而对从未闻法、恶业深重之人，此法号称仍有效，因为中阴身"记忆力九倍生时"、恐惧中求救心切，反而好教。换句话说，它自认是为中间的大多数人准备的：修行没成、作恶未满的普通人。另一条边界是它反复强调的师承：密法须灌顶传授，"未经如法灌顶，不得妄授"，扉页就印着"如要修习仍请觅求上师传授灌顶方为如法"。这本书自己承认，读文本不等于得到法。

顺带交代我的立场。这个译本正文之前有八篇民国居士高僧的序加一篇重译述缘，占了全书近五分之一，多为护法劝信之辞，夹着不少当年显密门户之争的意气话，普通读者可以直接跳到上卷正文，几乎没有损失。另外全书有一处真实的张力它自己没有处理：一边说五无间重罪之人"一经闻在耳识，亦得超度"，一边又用整整一段讲从未见过密像的持律法师如何"愈堕愈深"——听闻的门槛到底是零还是很高，两处说法打架。我读下来的判断是后者更接近全书本意：它反复要求生前熟习，说明"闻"从来不是白捡的。这个矛盾按住不放的读者，会比照单全收的读者收获多。

结论：因为人认熟悉，不认真相；业习让人把陌生当危险、把惯性当安全。

这是全书埋得最深的心理观察。六道的光是你无数世打转的老地方，颜色暗淡、亮度友好，像深夜回家看见自家楼道的灯；佛的智光是你从未直面过的本来面目，纯度太高，第一反应是躲。书里每一天的导示都在跟这个本能搏斗：它从不说"跟着感觉走"，恰恰说感觉是业力伪装的向导。把这条抽出来放到活人世界里也成立：让人沉沦的选择几乎总是舒服的，让人解脱的选择几乎总带着灼痛感。这条线后面还有大用。

边界：书里看的是光从哪来，不看它多亮。第六日之后连佛光也可能以可怖形态出现，所以"刺眼即正确"不能机械反用。

结论：温和的邀请你不理，只剩恐惧还能抓住你的注意力——忿怒是慈悲的加急件。

七天喜乐相接引全部失败之后，同一批佛换脸再来（换脸的来龙去脉第一层已交代）。这个设计的逻辑很硬：中阴的亡者昏迷复清醒、清醒复昏迷，能唤醒他的刺激阈值越来越高；柔光唤不醒的，惊雷或许可以。恐怖景象在这套体系里不是惩罚，是最后的叫醒服务。

边界：前提是亡者被教过"认出即解脱"。没受过这个训练的人，恐惧只会把他吓进更深的逃亡——书里有一组现成的反例，留到第八层细看。

结论：因为意生身没有肉体的迟钝做缓冲，心念直接兑现，教学立竿见影。

书末总结了四条：中阴身有微弱的通力，能领悟导示；生前耳聋的，中阴闻性完好；惊恐中的人求救心切，愿意听；记忆力九倍于生时。合起来是一幅奇特的图景：活人上课心不在焉，因为肉身给了他拖延的本钱；中阴身悬在业风里，每句话都是救命绳，注意力被恐惧调到最大。所以这部法不在人活得好好的时候讲大道理，专挑存亡关头递话。它对"什么时候人真正听得进话"有一套清醒的判断。

边界：同一机制反过来也成立——心念即现实意味着一个恶念也立刻兑现，"妄念一动，偶一取著，彼法即忽应念而生"。黄金窗口同时是高危窗口。

结论：它把"你如何来到这个世界"归因于一次无人监督的欲望冲动——投胎机制是欲望机制的显影。

闭胎门一节写：亡者见未来父母交合，对母生爱、对父生憎则成男胎，反之成女胎；在爱憎妒动念的一刹那，"忽感一刹那之欲乐，瞬即昏迷而失其知觉"，醒来已在胎中。剥掉宗教外壳，这段话的结构是：决定你一生起点的，是你在最无防备时刻的贪与嫌。而对治法也直白：认出那景象是幻，或者把它观成本尊双身，欲望无处落脚，胎门自闭。全书对"欲"的态度在这里最清楚：不在压制它，而在看穿它下注的那一瞬间。

边界：这是教义陈述，不是可验证的发生学；蒋维乔序里特意提醒，双身像密义在此，"以凡情推测圣境"必生误解。

结论：不垮。法庭是幻，账不是幻；"幻"否定的只是场景的实体，业的因果一分都没被否定。

业镜一节的精妙在两头都不放：一头，白石黑石数得清清楚楚，撒谎无用，业力精确记账；另一头，经文紧接着说司命鬼王、狱卒乃至受刑的身体"皆汝幻识所变，其体亦空，空能坏空，无有是理"。合起来：报应的形式是心造的（所以恐怖可以解除），报应的逻辑是铁的（所以生前行为躲不掉）。它用"幻"卸掉恐惧，同时用"业"保住道德，两根柱子各干各的活。

边界：这个平衡依赖听者理解"空不是没有"（书里原话，"此之所谓空，并非空无所有之空"）。把空听成虚无主义，整套伦理确实会塌，这是此法反复要求师承讲授的原因之一。

结论：因为对象是一个不断昏迷又醒来的意识，每次醒来都等于第一次听。

书里描述中阴身"昏迷复清醒，清醒复昏迷，极不安定"，所以这套教学与其说是四十九堂课，不如说是同一课的四十九次重播，每次换一个场景外壳：蓝光里讲一遍，白光里讲一遍，忿怒尊的獠牙前讲一遍，业镜前再讲一遍。只要有一次，亡者恰好清醒、恰好听进去，当下得度，"于一刹那间，即有大界分"。这是为极端不利的听讲条件设计的冗余：不指望每发都中，指望四十九发里中一发。

边界：重复的前提是内容零变化。变了说法，昏迷者醒来会当成新信息重新理解，反而误事。这条纪律，经文自己执行得近乎偏执，逐日导示连句式都不换。

结论：不违背，因为声音只负责提醒，认出必须自己完成；这是递纸条，不是替考。

此法号称五无间重罪之人"一经闻在耳识，亦得超度"，听着像廉价的免死金牌。但细看每一日的作法，念诵者做的只有一件事：描述现前的景象、指出它的来处、给出该做的观想。做不做、认不认，全在亡者。书里那个层层降级的结构也证明了这一点：如果他力真能包办，就不需要从净光一路退到择胎；每一次降级，都是亡者自己错过了那一刹那。所谓"闻解脱"，准确说是"闻提醒之后的自解脱"。

边界：书同时保留了真正的他力成分，诸佛"悲愿不舍"、一再放光，以及活人做功德可以转亡者业（眷属如法修福，"纵汝先当感投恶道，汝今必能改生上界"）。自力是主轴，他力是斜拉索，它没打算做成纯粹的哪一种。

一句话：死后四十九天里出现的每一尊佛和每一只鬼，都是你自己的心，认出来的那一刹那叫解脱，认不出来的那一刹那叫轮回。


读到全书最后几页，有一句话会让人停下来。这部通篇对亡者说话的经，在结尾忽然掉转头，对还活着的人下了一道指令：此法"于人生时亟应修学，受持之、读诵之，每诵三遍"，要"牢记于心"，牢到什么程度？"即令忽然而有数十百人追取其命时，亦不忘失"。哪怕几百人追杀你，也不能忘。

一部度亡的经，为什么要求活人背熟？想一层就通了：临终那半小时和死后那四十九天，学不了任何新东西。书里写得清楚，中阴身昏迷复清醒、被业风吹得身不由己，那种状态下能调用的，只有生前已经刻进骨子里的反应。念诵者在耳边喊"认出它"，可"认出"这个动作有个前提：你得见过。书里那组对照残酷又诚实：修过密法的人见到忿怒尊，"如旧识相逢"，一念证入；一辈子持戒讲经、却从未见过密乘图像的法师，同一景象前"发生仇异见解"，愈堕愈深（这就是第五层按下的那组反例）。决定生死分界的与其说是道德积分，不如说是熟悉度。死亡是一场闭卷考试，这本书是它唯一的教材，而教材只在生前发放。

所以这部经的真实用法是：活着的时候，把死亡的全部恐怖景象在脑子里预演到滚瓜烂熟：蓝光来了怎么办，獠牙来了怎么办，业镜前怎么办，看见父母交合的幻象怎么办。等真的躺在那里，耳边的念诵声只是在按响一个生前装好的开关。这就是消防演习的逻辑：火灾现场没人来得及思考，能救命的只有练过一百遍的那条逃生路线。楼里贴逃生图，从来不指望火灾那天才被人看见，指望的是你平时路过多看两眼。《中阴闻解脱》就是一张贴在人生走廊里的逃生图。

可是这里得停下来，对这个结论下狠手。如果它本质上是写给活人的，为什么不干脆写成一本活人的书？直接讲"你的恐惧都是自心投影"，何必绕道死亡、假托亡者、编排四十九天的日程？这一问才问出真正的底。因为这句话对活人几乎无效。对一个日子还过得下去的人说"恐惧皆是自心"，他点点头，觉得有道理，然后继续过日子。退路太多的人听不进绝对的话。只有死亡把一切退路拆光：肉身没了，亲人听不见你，家产分给了别人，连逃跑都跑不出自己的心。这部书选择在那个语境里说话，并非出于文学趣味：它清楚这句话的分量，需要一个没有退路的听众。借死人的耳朵，说给活人的心。预演死亡的人，等于提前体验了一次"退无可退"，那句话才第一次真的砸进来。

而一旦砸进来，你会发现全书的地图早就标注了这一点，只是措辞低调。书里给"中阴"下定义时列了六种：处胎中阴、睡梦中阴、禅定中阴、命终中阴、法界中阴、转生中阴。看清楚，六种里只有后三种和死亡有关。做梦是中阴，入定是中阴，甚至待在娘胎里就是中阴。所谓中阴，不过是"离开一处、未达另一处"的悬空状态。用这个定义扫一遍活人的日子：换工作是中阴，失恋是中阴，等诊断结果的那一周是中阴。而人在这些悬空时刻的表现，跟书里的亡者一模一样：慌不择路，专挑柔和舒服的那道光钻：熟悉的旧关系、麻痹的旧习惯、随便抓一个"下家"就投胎，投完发现是狗窝。书里对亡者喊的每一句，翻译过来都是对悬空期活人的忠告：别怕那道刺眼的光，别贪那道舒服的光，你看见的可怕东西是你自己的贪嗔痴变的，认出来，就不用跑。

最后剩一个细节，是这本书里最温柔的一处。整个体系层层降级，从当下成佛一路退到投胎转世，退到最底层，经文教的竟然是：好好挑一个胎，发愿生在能听闻佛法的人家。它没有在任何一层把人骂下地狱，失败七次之后，它教你怎么体面地再来一次。合上书想一想，这个结构对活人同样成立：最好的时机错过了，还有次好的；全错过了，就为下一轮攒一个好起点。一部关于死亡的书，最后一页写的是怎么重新开始。

《西藏度亡经》度的不是亡者，是还没死的你。

本篇所引经文与序文（导示语、六种中阴、记忆力九倍、狮子皮喻、闭胎五步、结尾嘱咐等）均出自张莲菩提 1936 年重译本原文。版本流传（达瓦桑杜喇嘛英译、伊文思-温慈纂集于牛津出版、张氏据英文本转译）出自书内诸序及重译述缘。此书在藏地属伏藏经典、托名莲花生大士所传，学界通说为十四世纪噶玛林巴发掘，此点为公认背景知识，书内未详述。《俱舍论》中阴身之说引自蒋维乔序。"消防演习""逃生图""闭卷考试"等类比为本篇作者所加，不出自原书；对"中阴六种"作现代生活引申亦属本篇的读法，非经文自注。中阴实相无法他证，本篇只述其义理结构，不对其真伪下断语。
