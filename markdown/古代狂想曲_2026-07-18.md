# 古代狂想曲

日本小说家池泽夏树在大英博物馆里挑了十三件（组）心动的文物，然后一件一件飞去它们的故乡：希腊、埃及、印度、伊朗、加拿大、柬埔寨、伊拉克、土耳其、韩国、墨西哥、澳大利亚……最后回到伦敦。文物是票根，真正的行程是问一个问题：五千年了，人到底变了没有？

先说这本书的怪写法：全书主角只叫"男人"，第三人称，其实就是作者自己。这个套着壳的"男人"在开篇就交代了出发的心境：整个社会化作一个过热的市场，人人追逐比对手领先一毫米的"新"，彷徨在兴奋与无聊之间。碰巧他遇到一位研究苏美尔文化的女性，看到五千年前的工艺品照片，比现今身边的物品还好看。于是一个念头生了根：女人二十岁生孩子，五千年等于二百五十代人；而我们连曾祖母的事都说不上几句。这么久远的时间里，人类精神世界的基本形态却并未改变，因为今天的他看苏美尔美术，依然觉得美。

整本书就是拿这个念头去各地验货。挑几段有代表性的：

大英博物馆 52 展厅的波斯斯芬克斯浮雕，男人的脸、狮子的身、鹰的翅。男人由它飞去伊朗，一路发现的却是转述权的问题：波斯帝国的历史，今天基本只能通过希罗多德等希腊人的记载去了解，连波斯波利斯这个地名都是希腊语，波斯语原名 Parsa 反而没人叫。帝国把对外宣传外包给了敌人，两千年后账单才寄到。

男人自问：看遍藏品，最让自己心动的到底是哪里的哪个时代？答案是高棉。他专门辨析那种微笑和蒙娜丽莎的区别：蒙娜丽莎只是"好像别有深意"，甚至有些故弄玄虚；高棉佛像的微笑来自天界，是超越人类的智灵之间交换的笑容。这一篇也顺带写了木与石的战争：吴哥的石头建筑正被榕树的根一寸寸掰开，永恒之战里石头未必赢。

大英博物馆的美索不达米亚藏品苏美尔多、亚述多，偏偏巴比伦少（当年挖巴比伦的是德国人）。男人惦记着，终于找到一只不起眼的"铜龙"，主神马尔杜克的神兽，样子像牧羊犬配了个食草恐龙的头。他还发明了一个概念：美术全集是"书籍形式的博物馆"，实物凑不齐，照片可以随心所欲，编一座自己的"空想博物馆"。

全书的思想高点。男人在爱丽丝泉的画廊里看原住民绘画，"站在那里的身体只剩一副空壳，魂魄已经飞入画里面"。他由此想到一个对比：其他文明表现精神，总要投入巨大的物质——金字塔造型完美，但后人赞美的与其说是设计，不如说是让奇迹得以实现的强制劳动体系，"我们今天过于物质化的文明就在其延长线上"。而原住民文化里，精神已经从物质中解放出来，能够独立存在：一块二十厘米的圣物 tjuringa，几笔刻痕，装着整个宇宙观。

最后两篇写伦敦本身：这座城市半个身子朝向海外，保守外表下对新奇事物开放（粉色的复古出租车印着网站广告）。也不回避账本的另一面：英国人爱上红茶，对华贸易赤字，于是把印度鸦片卖进中国。大英博物馆的收藏热情和鸦片战争，是同一种"对海外的巨大热情"的两副面孔。

情感基调：好奇、松弛、带一点对现代生活的倦意。美学特征：文物描写极具体（斯芬克斯"左前足像狗一样抬起，很是可爱"），议论则轻拿轻放，从不趁机上课。作者位置：始终是个买了门票的旁观者，不是学者也不装学者，书末还请了思想家鹤见俊辅写解说压阵。

作者动机（文本推测）：开篇那段对"过热市场"的厌倦不是闲笔，是全书的引擎。池泽夏树写这本书的年代正是日本消费社会烂熟期，他需要一个足够长的时间尺度来对冲"每天都在过节"的空转感，五千年、二百五十代人，就是他给自己配的解药。选大英博物馆当起点而非奈良正仓院，也有意思：他要的是全世界文明摆在一个屋檐下互相打量的那个视角。

作者盲点：这本书对"文物怎么到的伦敦"处理得相当轻。鸦片战争提了，帕特农大理石的归还争议、殖民掠夺的账，基本绕开。他选择把大英博物馆当作中性的取景框来用，这让全书轻盈，也让它在今天读来缺了一块：同一批文物，希腊人、埃及人、原住民后代看过去，不是"狂想曲"，是讨还清单。

跨域映射一条：波斯把宣传外包给希腊人的教训，和企业把品牌叙事外包给媒体是同一个结构。你不自己讲自己的故事，最终流传的版本就由别人的利益和趣味决定，连你的名字都会被换成别人语言里的叫法。对得上的点在"转述权"：谁写下来，谁就拥有了过去。

行动触发：下次逛博物馆，试试男人的玩法，别按展厅顺序走，先快速扫一圈，只停在真让你多看了三秒的东西前面，记下它，回家查它的故乡。一件文物配一次深挖，比五十件都拍照强。这也是他"空想博物馆"的用法：收藏不需要产权，需要的是挑选。

读者立场：十三段旅程质量不齐。澳大利亚、伊朗、柬埔寨三篇最好，有真问题；韩国篇和加拿大篇偏薄，更像规矩的游记；埃及篇的造船人一章材料好但收得急。我最被说服的是金字塔那个翻转。它的代价是承认我们对"伟大文明"的赞美里，混着对强制劳动体系的赞美，这个代价池泽夏树自己认了，没绕。

```
大英博物馆（万物一屋檐）
        │ 挑一件心动的
        ▼
   飞去它的故乡 ── 波斯：名字被希腊人改写
        │          高棉：天界的微笑
        │          巴比伦：一只像狗的龙
        ▼
   验货：还美吗？ ── 美 → 五千年，人没变
        │
        ▼
   澳大利亚给出反题：精神可以不装在物质里
```

第一层按下没展开的那个对比，值得单独拿出来讲透：金字塔和 tjuringa，一个是人类最大的石头建筑之一，一个是二十厘米的刻纹圣物，池泽夏树把它们放上了同一架天平。

他的原话大意是：金字塔造型完美，但为了在大地上实现这种完美，必须投入庞大的劳力；结果后人赞美的与其说是设计之美，不如说是让它成真的强制劳动体系。文明所推崇的，是"奇迹得以实现"的组织能力。然后一句补刀：我们今天过于物质化的文明，就在金字塔的延长线上。而澳大利亚原住民走了另一条路。精神直接画在岩壁上、刻在圣物上、唱在歌里，从物质中解放出来，独立存在。

先攻这个核：这会不会是浪漫化？原住民不建金字塔，也许不是不想，是人口和技术不允许——把"没能力做"说成"选择不做"，是旅行文学最常见的美化。这一攻能站住一半：原住民确实没有建造巨构的技术路径。但另一半攻不动，因为池泽夏树的重点不在"他们为什么不建"，在"不建的文化照样把精神生活过满了"。四万年，岩画、歌之路、tjuringa，精神传承从未断线。这至少证明了一件事：精神强度和物质投入之间，不存在必然的换算关系。金字塔路线是一种选择，不是唯一解。

拿搬家来试这个道理，严丝合缝。谁都见过两种人：一种人的"生活质量"全部长在家当上，房子越换越大，柜子越塞越满，搬一次家像搬一座小金字塔，人被自己的物质压得直不起腰；另一种人东西极少，但一顿认真做的饭、一个持续二十年的爱好、几段维护得很好的关系，日子的密度反而更高。前一种是把幸福外包给容器，后一种是让幸福独立于容器。池泽夏树在开篇写下"最重要的事莫过于幸福"时，其实已经预告了澳大利亚这一站是全书的终点站：前面十一段旅程看的都是精神的各种容器，这一站看到了不用容器的精神。

"咦"的瞬间在这里：这本书开头的病（过热市场、每天过节的空转）和结尾的药（不依附物质的幸福感）之间，隔着整整十三段旅程，池泽夏树从头到尾没把这层说破。他只是把两百五十代人的东西一件件摆给你看：美过的还美，帝国的名字被改写，石头输给树根，刻痕赢过金字塔。看完自然会算这笔账：五千年里人类攒下的物质翻了不知多少万倍，而"创造出让自己满意的东西本身就是幸福"这件事，苏美尔的工匠和爱丽丝泉的画家之间，一毫米都没挪动。所谓古代狂想曲，狂想的不是古代，是我们以为自己进步了。

本篇所引开篇心境、五千年二百五十代人之算、苏美尔工艺品之美、波斯斯芬克斯与希罗多德转述、高棉微笑与蒙娜丽莎之辨、铜龙与空想博物馆、金字塔与强制劳动体系之论、tjuringa 与原住民绘画、红茶与鸦片战争、粉色出租车，均出自原书。目录篇目以原书为准。"男人即作者自己"为通行读法；第八层"病与药首尾呼应"的结构解读、搬家类比，是解书者的读法，非作者自述。池泽夏树的写作年代背景为解书者补充的公认背景。

狂想的不是古代，是我们以为自己进步了。
