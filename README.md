# 青山深度阅读
我一直在思考，一本书如何读？是花费一周细细品尝，还是花费10分钟粗读，后来发现在没读这本书之前，我不清楚它值不值得我花费太多时间，所以我尝试进行深度阅读的解书，通过一万字左右的通读，我可以清晰的知道哪些书是有意思的书，哪些书是不适合我的，然后再进行深度的细读。整理了很多以后我觉得应该把它开源分享给有缘分的读书人。

> 读一本书，不是为了尽快把它变成结论，而是为了让它在自己身上多发生一会儿。

这里收着青山的深度阅读：历史、文学、哲学、宗教、社会科学，也有一些难以归类、却值得追问的书。每一篇都试着越过“这本书讲了什么”，继续问下去：作者真正困惑的是什么？他的答案立在什么前提上？哪些地方照亮了我，哪些地方我仍然不同意？

我愿意把这些私人阅读摊开，并不是因为它们已经成熟。恰恰相反，是因为理解本来就会变化。今天笃定的判断，明天可能需要改写；一篇解读留下的，不只是答案，也是一个人在某个时刻怎样走近一本书。

## 我怎样读

这些文章通常从几个朴素的问题出发：

1. 作者究竟在回答什么问题？
2. 全书纷繁的材料下面，真正起作用的是哪几条线？
3. 这些论证依赖什么前提，又会在哪里失效？
4. 把书放回作者的时代，再放回今天，它还能照见什么？
5. 读完以后，人的看法或行动是否会有一点具体变化？

这不是统一格式的承诺。不同的书有不同的脾气：小说需要跟人物多待一会儿，历史要分清材料和判断，理论著作则要把论证拆开。所谓“深度”，不在篇幅长，而在有没有真正碰到书的骨头。

## 三条诚实的边界

**它不是原书的替代品。** 解读只是一扇门。若一篇文章让你觉得“这本书我已经读完了”，它反而可能把门关上了。最好的结果，是让人愿意回到原书，或者带着一个更好的问题离开。

**它不是权威答案。** 这里有事实转述，也有我的理解、推断和偏爱。两者并不总能切得干干净净。欢迎指出错漏，也欢迎提出一套真正不同、而且完整的解释。

**它有人与 AI 的共同劳动。** AI 参与了资料整理、结构梳理、语言打磨与格式转换；选什么书、追问什么、保留什么、修订什么以及是否公开，由青山作出选择并承担责任。工具可以帮助铺开材料，不能替人阅读，也不能替人负责。

## 内容提醒

这间书房保留了真实的阅读跨度，部分文章涉及成人议题、暴力、战争、政治、宗教与创伤经验。它们被保留，是因为阅读不应只面对舒适之物；但保留不等于赞同，分析也不等于鼓励。请按自己的年龄、处境与承受能力选择阅读。
