## 目 录

# 聚焦跌出全球化增长列车的底层十亿人四大贫困陷阱

牛津大学经济学教授、世界银行前发展研究部主任保罗·科利尔在这部颠覆传统发展经济学的经典著作中，提出了一个极为冷峻的全球分化诊断。二十世纪末以来的全球化浪潮确实帮助中国、印度等发展中大国实现了人类历史上规模最大的脱贫奇迹，让近五十亿人口搭上了经济增长的高速列车。然而，在世界的聚光灯之外，生活在大约五十个失败国家之中的十亿人口，不仅没有分享到全球化红利，其人均实际收入反而持续倒退，陷入了停滞甚至绝望的深渊。科利尔称他们为最底层的十亿人。

科利尔以极具震撼力的计量经济学实证研究，击碎了新自由主义市场万能论与传统左翼外援无用论的双重神话。他指出，这五十个国家之所以无法像东亚国家那样通过劳动密集型制造业实现腾飞，非因为他们不够勤劳，而是因为他们被深锁在四套相互交织、自我强化的结构性陷阱之中：冲突陷阱、自然资源陷阱、内陆与恶邻陷阱，以及恶劣治理的小国陷阱。一旦一个国家掉入这些陷阱，市场机制不仅不会自动修复平衡，反而会加速资本外逃、人才流失与暴乱循环。

为了拯救这跌入深渊的十亿人，科利尔开出了一剂极具争议却无比切中要害的处方。他坚决主张彻底改革现行以单纯金钱捐赠为主的援助模式，提出整合国际贸易优惠政策、设定具有法律约束力的跨国法律与监管标准，乃至在极端情况下动用有限度外部军事干预来为脆弱政权提供安全防护网。这部著作是当代全球治理与发展战略不可逾越的里程碑。

# 内战周期回归模型、荷兰病资源诅咒与恶邻包围地理阻隔

第一个坚实实证指向暴力冲突的自我复制循环，即｜低收入与经济停滞将内战爆发概率推高至一般国家二十倍的冲突陷阱｜。科利尔通过跨国回归分析证明，贫困与内战构成了致命的双向因果闭环。一场长达五年的内战平均会摧毁一个国家百分之十五的国内生产总值，而一旦走出内战，由于武器泛滥、战时走私网络成型以及退伍军人无业，该国在战后第一个十年内再度爆发内战的概率高达百分之五十左右，使发展红利彻底化为灰烬。

第二个实证指向资源财富对经济肌理的摧毁，即｜荷兰病本币升值与大宗商品价格暴跌引发的自然资源诅咒｜。科利尔挖掘了尼日利亚、刚果金等国的经典悲剧：石油和钻石的大量出口导致该国货币汇率被人为高估，这不仅瞬间击垮了本土原本具备国际竞争力的农业和制造业，还引发了极其恶劣的寻租政治。政客们不再需要向民众收税，因而无需建立透明的问责政府，所有的政治博弈彻底沦为围绕资源出口特许权的武装分肥。

第三个实证指向地理区位的致命锁死，即｜深处内陆且被同样贫困混乱邻国包围的地理隔离绝境｜。如果一个国家处于内陆（如乌干达、布隆迪），且周围的邻国同样陷入贫困、暴乱或基础设施瘫痪，该国走向国际市场的运输成本将高得惊人。瑞士和奥地利虽然也是内陆国，但它们的邻居是德国和法国，它们可以通过为富裕邻国提供过境服务而致富；而在非洲内陆，邻国非市场，而是输送难民、武器与走私武装的灾难策源地。

# 政变政权更迭、宗派分肥冲突与小国劣质治理三大闭环齿轮

科利尔拨开繁杂的发展经济学图表，提炼出锁死脆弱国家命脉的三大制度闭环齿轮。

第一齿轮是政变频发与资本大逃亡的逆向选择机制。在最底层国家，政治权力的更迭往往不是通过民主选举，而是通过军官政变完成的。缺乏稳定的法治预期导致本国精英根本不敢进行长期固定资产投资，他们将通过特权掠夺来的财富全部兑换成外币转移至瑞士或伦敦银行。统计显示，非洲撒哈拉以南地区的私人财富有高达近四成存放在海外，一个自身资本疯狂外逃的地区，绝不可能依靠外部援助实现内生增长。

第二齿轮是部落身份政治对国家能力的碎片化绞杀。在缺乏共同国民认同的失败国家，民主选举往往退化为宗派人口普查。选民不是投票给具有治理能力的候选人，而是纯粹按照部族血缘站队；获胜的政治派系则把国家财政视为战利品，公然向本部落发放庇护性肥缺，彻底瘫痪了现代文官官僚系统的专业化与中立性。

第三齿轮是规模过小导致的治理成本畸高与市场缺乏吸引力。最底层十亿人被分割在大约五十个微型主权国家之中，平均人口仅有几百万。过小的市场规模不仅无法形成现代工业所需的产业集聚效应与专业化分工，而且每一个微型国家都要供养庞大的外交使团、国防军队和政府部门，导致行政成本居高不下，对国际跨国制造业投资完全丧失了吸引力。

# 从发展经济学常识直抵全球市场失灵对脆弱国家的结构性锁死

顺着科利尔建立的微观计量模型，我们得以洞穿全球化表象之下残酷的市场失灵真相。

第一层下钻击碎了后发劣势会自动消弭的平庸乐观论。传统经济学假设贫困国家拥有极低的劳动力成本，因此资本会自动流向洼地以实现收敛。然而科利尔指出，当东亚国家率先建立起庞大的产业集群与高效供应链后，亚洲已经占据了全球制造业的先发集聚优势。对于非洲内陆国家而言，即便工资水平比亚洲更低，其高昂的物流成本、脆弱的电网和腐败的关卡也会彻底抵消劳动力红利，全球自由贸易在客观上正在把底层国家永远排斥在工业化大门之外。

第二层下钻揭示了国际主权平等的法律虚构与实际治理能力的断层。战后国际秩序赋予了每一个微型国家完全排他的主权豁免，然而这种主权往往沦为腐败暴君肆意屠戮国民、洗劫国库的合法遮羞布。西方银行一边高喊反洗钱，一边极其顺畅地吸收着来自贫困国家的掠夺资金；国际武器商人则在合法贸易的掩护下源源不断地向军阀输送杀人军火，国际社会用主权教条免除了自身应尽的监管干预义务。

第三层下钻触及了现代富裕社会对底层苦难不可推卸的连带责任。最底层国家的崩溃绝非遥远大陆的孤立悲剧。冲突陷阱催生出跨国恐怖主义基地，环境恶化与资源枯竭逼出数以百万计的难民潮，疾病与疫情在全球流动中肆虐。科利尔警告西方世界：如果我们不能帮助最底层的十亿人走出陷阱，那座贫穷的火山终将喷发出毁灭全球秩序的滚滚熔岩。

# 六大发展援助与治理重构推演：超越传统金钱赠予的干预范式

推演一，如何重构发展援助的资金投向？必须坚决停止向腐败政权的国库直接注资，将有限的援助资金集中投向跨国交通走廊建设与基础公共卫生，用硬资产和生命指标直接绕开官僚寻租。

推演二，国际贸易政策如何向最脆弱国家倾斜？富裕国家应当单方面取消针对最不发达国家制造业产品的关税与配额壁垒，同时放宽原产地规则限制，为其争取长达十至二十年的出口保护窗口期。

推演三，如何打击跨国资源掠夺中的黑金交易？全球金融中心必须强制要求所有跨国矿业公司公开支付给东道国政府的每一笔特许权费用明细，对隐瞒黑金的国际银行实施毁灭性二级制裁。

推演四，国际社会如何有效提供安全保障？非洲联盟与联合国应当建立联合快速反应维和部队，对经民主选举产生的合法新政权提供为期数年的安全保卫承诺，坚决遏制退役军官发动的军事政变。

推演五，企业组织如何防范荷兰病式的资源诅咒？当企业某一项高利润主业带来暴利现金流时，必须建立独立的战略投资基金，严禁将短期红利随意转化为推高全公司运营成本的常态化开支。

推演六，小微经济体如何打破地理恶邻困境？内陆小型经济体必须放弃大而全的自给自足幻想，全力押注跨境数字贸易、离岸金融监管与轻资产专业服务，用数字化通道穿透地理物理阻隔。

# 审视新干涉主义军事保障提议在主权时代的合法性争议

保罗·科利尔的实证分析极为锋利透彻，但他提出的某些政策药方在国际实践中引发了巨大争议。

首先，关于外部军事干预的建议面临难以逾越的政治与伦理风险。科利尔主张西方大国或维和部队应当在最底层国家政权更迭期进行军事驻防以防政变，但伊拉克战争与阿富汗重建的惨痛教训证明，外部军事力量极易被当地民众视为帝国主义占领军，不仅无法带来持久稳定，反而会激化极端民族主义与宗教极端势力的反弹。

其次，全书强烈的自上而下技术官僚设计色彩，有时低估了底层社会自身的非正规治理韧性。科利尔高度依赖自上而下的国际条约、外部监管与技术援助，对非洲本土古老的部落调解机制、非正规信用网络与草根自组织在极端贫困中的生存自救智慧关注不足。

行动触发：在评估任何涉及弱势群体的帮扶方案时，坚决摒弃只发钱不建机制的懒政思维，把精力聚焦在打破恶性循环的结构性杠杆设计上。

# 最底层的十亿人四大陷阱交互矩阵与外部脱困杠杆

# 为什么给非洲穷国直接发钱，反而常常把他们害得更穷？

很多人一看到电视上那些非洲瘦骨嶙峋的孩子，第一反应总是很善良：我们全世界富裕国家多捐点钱，把几百亿美元直接打过去，不就能帮他们把路修好、把肚子填饱了吗？保罗·科利尔在这本书里用硬邦邦的数据告诉你，这种好心往往会办大坏事。

想象一下，一个国家的政府被一个贪婪残暴的军阀把持着。这个军阀平时靠着卖本国的钻石和木材过日子，根本不把老百姓当人看。如果你这时候把一百个亿的扶贫资金直接打进这个国家的财政账户，会发生什么事？第一，军阀和他的亲信会立刻把这笔钱贪污掉一大半，存进他们在瑞士的秘密账户里，或者用来买更多的军火去镇压反对派；第二，有了这笔白送的钱，军阀就更不需要向老百姓收税了，老百姓在政治上就更没有筹码要求政府建医院、建学校。

更糟糕的是，突然涌入的大量外币会导致这个国家本国的货币急剧升值，这在经济学上叫荷兰病。货币一升值，本地农民种出来的粮食在国际市场上变得特别贵，根本卖不出去，原本能勉强维生的本地工厂瞬间倒闭，更多的人失去工作只能去当土匪打内战。所以科利尔说，单纯发钱非但救不了底层十亿人，反而是在给那些吸血的暴君源源不断地输送营养液。真正管用的办法，是帮他们封死贪官洗钱的银行通道，给他们的工厂减免出口关税，派维和部队帮他们看住大门别被军阀政变推翻。只有把这些结构性的绳套解开，他们自己的手脚才能动起来。

# 摆脱贫困需要的不是廉价的同情，而是用严密的制度杠杆打破恶性循环

《最底层的十亿人》彻底重塑了二十一世纪全球发展政策的智识地貌。保罗·科利尔用冷峻的理性证明，盲目的道德热情无法驱散贫困的阴霾。当五十个国家在历史的深渊中挣扎时，人类文明的真正尊严在于拿出勇气与智慧，用法律、贸易与安全的综合手术刀，精准斩断缠绕在底层十亿人脖颈上的制度枷锁。

事实边界说明：本书解读严格基于保罗·科利尔在牛津大学出版社及理想国出版的《最底层的十亿人：贫穷国家为何失败？》（The Bottom Billion）中文译本。书中关于内战爆发概率模型、自然资源收益流失比例及战后复发周期的统计结论，均来自世界银行发展研究部对全球一百多个国家近五十年宏观经济数据的量化回归分析。
