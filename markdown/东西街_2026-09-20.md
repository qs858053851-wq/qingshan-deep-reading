# 将家族秘密与国际法源流熔于一炉，追索现代法治文明保护个体与保护群体的两大支柱如何在屠杀废墟中破土而出

伦敦大学学院法学教授、著名国际人权律师菲利普·桑兹在这部荣获贝利·吉福德非虚构图书奖的杰作中，完成了一次令人叹为观止的智识侦探与历史打捞。全书由一连串看似不可思议的地理巧合贯穿始终：位于今日乌克兰西部的古城利沃夫（曾名伦贝格、利沃夫、利沃夫斯克），在二十世纪的狂风暴雨中经历了奥匈帝国、波兰第二共和国、苏联、纳粹德国以及战后苏联的反复蹂躏。正是这座经历过惨烈犹太人大屠杀的小城，奇迹般地孕育出了现代国际刑法的两位开山鼻祖：提出危害人类罪的赫希·劳特派特，与提出灭绝种族罪的拉斐尔·莱姆金。更为宿命的是，二人在纽伦堡审判中共同控诉的纳粹波兰总督汉斯·法郎克，恰恰是下令屠杀他们留在利沃夫全部家人的刽子手。

桑兹将这四条命运线交织在纽伦堡六百号审判室的宏大穹顶之下，展开了一场关于正义哲学的终极辩论。劳特派特的法理基石立足于启蒙个人主义，他坚信法律的最高天职是捍卫每一个具体个体的尊严与生命权，任何将人划归为抽象群体的做法都是纳粹主义的同谋，因此必须以危害人类罪惩处国家暴行。莱姆金则从亚美尼亚大屠杀与波兰森林的血泪中得出相反判断，他坚信暴行从来非针对单个人的，受害者之所以被杀，仅仅因为他们是某个特定种族的成员，因此必须发明灭绝种族罪这一全新法律武器，赋予群体以独立的受保护实体地位。

这部著作是二十世纪法哲学演进的最顶级个案透视。它深刻证明，人类在经历奥斯维辛的工业化屠杀后，正是依靠这群法律人在词语与概念的无边废墟中，一砖一瓦地重新搭建起了守护人类文明底线的法治防线。

# 伦贝格大学法学渊源、纽伦堡600号审判庭辩词与汉斯·法郎克日记档案的实证检验

全书的第一个坚实法哲学史实证指向劳特派特在利沃夫大学的学术启蒙，即｜赫希·劳特派特在伦贝格大学确立的以个体基本人权对抗国家主权的法理突破｜。在传统国际法体系中，格老秀斯确立的原则是国家主权神圣不可侵犯，主权国家在国境内如何处置本国国民纯属内政，国际法无权置喙。劳特派特通过极具革命性的法学论文证明，当国家机器蜕化为杀害自身公民的犯罪组织时，国家主权便丧失了合法性屏障，每一个自然人的人权直接受国际法最高法秩序保护，这直接奠定了战后联合国《世界人权宣言》的理论地基。

第二个实证指向拉斐尔·莱姆金孤身一人的立法游说传奇，即｜拉斐尔·莱姆金生造Genocide词根并以联合国公约确立灭绝种族罪｜。莱姆金将希腊语中的种族（genos）与拉丁语中的杀戮（cide）拼接，创造了灭绝种族罪这一专属词汇。桑兹详尽挖掘了莱姆金在一九四五年纽伦堡起诉书起草过程中的惨烈博弈。当时英美检方最初拒绝采纳这一未经判例检验的生造词，莱姆金奔走于各国代表团之间，凭借对纳粹掠夺法令的详尽文本分析，硬生生将灭绝种族罪写进了第三项战争罪行起诉指控之中，并最终在一九四八年促成了联合国大会通过《防止及惩治灭绝种族罪公约》。

第三个实证则是纳粹波兰总督汉斯·法郎克在纽伦堡法庭上的毁灭性证词，即｜汉斯·法郎克三十八卷战时日记揭露的利沃夫省犹太人灭绝清算全纪录｜。作为希特勒当年的私人法律顾问、纳粹法学会主席，法郎克极为荒谬地自诩为法治守护者，却用三十八卷皮面日记详细记录了如何在波兰总督辖区实施最终解决方案，如何在利沃夫瓦尔基公园进行公开绞刑。当劳特派特在公诉席上听着法郎克宣读日记时，他刚刚获知自己在利沃夫的母亲、姐姐和侄子已在法郎克签署的第十二号清场令中全部遇害。

# 个体权利绝对优先、群体法律实体化与极权官僚法制化三大司法动力学齿轮

桑兹穿透繁杂的国际法庭诉讼文书，提炼出塑造现代人权法治体系的三大动力学机制。

第一齿轮是劳特派特的个人主义防护罩机制。劳特派特敏锐地察觉到，将人类按照民族、宗教或阶级划分为不同群体的思维方式，本身就是滋生法西斯暴行的思想温床。如果法律将保护重心放在群体之上，就会反向强化群体之间的身份边界，最终导致群体内部对异见的清洗以及群体之间的殊死搏斗。因此，法律必须穿透一切集体的迷雾，直接确立个体的不可侵犯性，每一个生命都拥有不受国家非法剥夺的独立价值。

第二齿轮是莱姆金的群体灭绝阻断机制。莱姆金针锋相对地指出，现实生活中的大屠杀组织者绝非把受害者当作个体来杀害的。一个犹太钢琴家之所以被送进毒气室，与他的个人才华、道德品行毫无关联，仅仅因为他是犹太群体的一个分子。如果在法律上不承认群体作为一个整体的受保护权利，就无法精准惩治那种旨在消灭整个文化、肉体繁衍能力的系统性灭绝暴行，法治就等于在最具毁灭性的罪行面前自我缴械。

第三齿轮是极权体制将犯罪行为程序化、法制化的堕落机制。汉斯·法郎克的经历揭示了现代法治最恐怖的变异形式：纳粹政权并非完全践踏法律，为通过颁布成百上千项条文严密的帝国法令，将掠夺、驱逐与屠杀伪装成依法行政的合规行为。当法律被剥离了基本的人道伦理与自然法正义底线，沦为统治者权力的纯粹工具时，受过顶级法学训练的法官与律师便迅速堕落为最高效的杀人帮凶。

# 从纽伦堡审判的博弈直抵现代法律对人类集体仇恨的防卫边界

顺着桑兹对这两大罪名的思想溯源，我们直抵法学哲学中最深沉的辩证张力。

第一步追问击碎了胜者正义的虚无主义指责。纽伦堡审判在程序上确实存在不可否认的战胜国管辖妥协，但劳特派特与莱姆金注入其中的法学思想，实现了人类司法史上的惊险一跃：彻底埋葬了罪刑法定原则中关于主权豁免的陈腐教条，确立了反人类暴行无论是否符合本国法律，都必须在普遍管辖权下面对独立法庭审判的最高伦理准则。

第二步揭示了个体权利与群体认同之间不可消除的内在悖论。我们今天的生活依然在这两大罪名的张力中被反复塑形。如果我们只强调劳特派特的个体人权，在面对卢旺达大屠杀或斯雷布雷尼察惨案时，往往会显得反应迟缓、定性无力；但如果我们过度沉溺于莱姆金的群体身份政治，又极易在社会内部制造出无穷无尽的族群对立与受害者特权争夺。

第三步触及了人类用语言重构正义的终极尊严。面对数百万人的无辜惨死，最容易产生的反应是狂暴的报复或彻底的虚无。劳特派特与莱姆金在极度的个人绝望中，选择用最冷静、最严密的法学概念，为人类的不可名状之恶命名。唯有被准确命名的罪行，才能在未来的历史中被有效识别、预防和审判。

# 六大司法与组织伦理推演：从规则合规陷阱到制度防恶机制的实践边界

推演一，如何识别组织内部的程序合法性伪善？警惕所有形式上符合条文规定、但在实质上公然践踏基本人道底线或剥夺特定群体生存权的所谓合规制度，形式合法绝不等于实质正义。

推演二，面对群体冲突时如何保持客观的裁决立场？在定性争议时，必须始终坚持劳特派特的原则，首要核实每一个涉事具体个体的真实行为与责任，坚决反对依据身份标签进行连坐与集体定罪。

推演三，立法与规则制定如何平衡普适性与特殊性？在确立普遍适用于所有成员的基本权利清单之后，方可设立针对弱势边缘群体的专项保护兜底条款，严防身份权利反噬普遍人权。

推演四，专业技术人员如何守住自己的职业伦理底线？律师、工程师、审计师等专业人士必须清醒认识到，专业知识必须臣服于人类基本善良良知，绝不能用专业技术去为反人类的系统作恶进行精致洗白。

推演五，历史创伤之后如何建立持久的社会和解？和解必须建立在司法对罪责的严谨个体化认定之上，既不能搞法不责众的和稀泥，也不能搞全民族负罪的仇恨代际传递。

推演六，跨国治理机构如何避免沦为大国政治的附庸？国际裁判机构必须拥有完全独立于出资国与创始会员国的自主司法管辖权与预算保障，确保任何超级大国的暴行同样面临司法追责。

# 审视桑兹家族寻根叙事对客观法理分析的潜在情感扰动

桑兹的非虚构写作为当代非虚构作品树立了标杆，但读者在领会其思想时仍需保持理性的警觉。

首先，全书带有极其强烈的个人家族追思色彩。桑兹的祖父莱昂正是从利沃夫逃亡西欧的幸存者，作者在挖掘劳特派特与莱姆金的同时，大量穿插了自己寻访家族失散亲人与纳粹后代的私人旅程。这种文学手法虽然极大增强了情感共鸣，但在某些章节中不免打断了法理学论辩的严肃推进，略显散文化倾向。

其次，全书对纽伦堡审判中苏联法律顾问波德戈尔内等人的贡献有所低估。实际上在纽伦堡法庭的法理构建中，苏联法学家虽然深受斯大林专制政治的操控，但其提出的侵略罪这一罪名概念，与危害人类罪共同构成了审判的三大支柱，桑兹在书中对此涉及相对简略。

行动触发：当面临一个要求你对特定群体实施差别化排挤待遇的管理指令时，立即要求对方出具书面法律依据，并在心里用劳特派特的个体原则质问这一决定的伦理正当性。

# 为什么说把杀人犯的名字叫成反人类或者灭种，在法律上有那么大的区别？

很多人第一次听说危害人类罪和灭绝种族罪的时候，觉得这不都是大规模杀人吗？为什么纽伦堡法庭上的大律师们要为一个新名词吵得不可开交？桑兹在书里讲清楚了这个至关重要的差别。

在第二次世界大战之前，全世界的法律其实都拿希特勒没办法。因为当时的国际法规定，一个国家的政府在自己家里怎么杀自己的国民，那是人家自己的内政，别的国家无权干涉。希特勒只要在德国通过几条法令，说杀犹太人是合法的，在法律层面上他就非杀人犯。这有多荒谬？

于是，从利沃夫走出来的两个天才法律人，拿出了两把完全不同的武器。劳特派特说，每一个活着的人，不管你是德国人、犹太人还是法国人，你作为人的尊严和生命权是老天爷给的，任何国家、任何政府制定的法律，只要敢侵犯你的基本人权，那个统治者就犯下了危害人类罪，全世界的法庭都可以抓他。而莱姆金说，纳粹杀人非一个一个杀的，他是要把犹太人或者吉普赛人整个种族从地球上抹掉，这叫灭绝种族罪，法律必须明确保护群体的生存权利。正因为有了这两个词，纽伦堡的法官才能把希特勒的手下拉上审判席，判他们反人类绞刑。这两个词非文人的文字游戏，它们是人类在尸骨堆里给全世界所有的暴君戴上的法律手铐。

# 正义从来非抽象的天赋之物，它是法学家在人类最黑暗的深渊里，用带血的词语亲手锻造的武器

《东西街》让我们重新确信了法治与文明的力量：即使城市被夷为平地，即使亲人全部死于非命，只要人类能够为罪恶给出不可辩驳的法律定义，正义的钟声就终将在历史的废墟中重新敲响。
