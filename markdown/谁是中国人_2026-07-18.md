# 谁是中国人

作者的履历本身就是这本书的方法：生于福建、长于香港、留学日本、任教冲绳与台湾，长年研究"边陲东亚"。他的评论文集围着一个悖论打转：汉唐盛世万邦来朝，为什么今天国力迎来高峰，香港与台湾对"中国人"这个身份的认同反而不增反减？

这是一本时评文集，文章多出自《明报》等专栏，按题分三部：第一部台湾（"告别中国"的历史拐点），第二部香港（"后雨伞时代"的去边陲化），第三部两场运动的对读（太阳花与雨伞）。附录一篇谈中港台身份认同与普世关怀。成书于 2017 年，正是太阳花（2014）与雨伞运动（2014）之后、局势剧变之前的窗口期。

自序里作者把全书的问题意识列成四问，值得原样转述：一、当年万邦来朝，为何"中国崛起"迎来高峰之际，已回归的香港与未统一的台湾向心力不增反减？二、英国殖民香港一个半世纪未曾出现"港独"思潮，为何回归之后反而爆发史上最大规模抗争、激发本土意识？三、大陆经济吸引力理应更吸引经济低迷的台湾，为何实际引发的是更大的戒心？四、台湾人认为中华人民共和国是"祖国"的仅有 0.1%，香港年轻人的这一认知也在急速下降。"祖国"这个词，为何在两岸三地出现截然不同的认知？

他的分析工具箱里最重要的两件。其一是"边陲东亚"框架：台湾、香港、冲绳这类经历过归属变更的边陲地区，与"中心"存在结构性的先天矛盾，中心压力越大，"去边陲化"（要求自主）的反弹越强；2014 年三地不约而同的"造反"（太阳花、雨伞、冲绳反基地普选），在他看来是同一个结构的三次发作。其二是安德森《想象的共同体》——他早在 2000 年就提出"香港共同体"概念，把香港人认同定位为"准民族主义"：有强烈的我群边界，但尚未走到独立诉求。

书里的关键事实线：台湾方面，中研院调查显示在"中国崛起飞跃期"（GDP 相继超越 G7 各国、2010 年跃居世界第二），台湾社会对大陆的认同不增反减；断交潮下，民调里"宁可邦交国归零也不愿砸钱"的比例高达 99.5%。香港方面，港人自认"中国人"的比例在 2008 年北京奥运时达到历史新高，随后一路下行，2014 年普选方案落空与雨伞运动之后，年轻世代转向本土主义。他由此点出一个常被忽略的时间点：香港认同的转折不在回归那天，在 2008 年之后。认同曾经真实地升上去过，又被具体的事一件件消耗掉。

写作姿态：学者写时评，数据和概念都在，但立场不藏：他认为北京"懲罚式"的做法（压缩国际空间、断交战）已被证实无助于争取民心，甚至反效果；同时他也批评把希望寄托在"经济融合自然带来认同"的一厢情愿。两边的天真他都不接。

全书几十篇文章，反复验证的是同一个命题：**身份认同的方向，由对待方式决定，不由实力对比决定。**

这根线能把书里的主要现象都推出来。实力逻辑预测：大陆越强，统一吸引力越大，认同应该回流，这正是"经济牌"“惠台”思路的前提。但书里的数据全部反向：崛起飞跃期恰是台湾离心力最强的时期；香港认同的高点出现在 2008 年（北京奥运，那是"被尊重地共享荣耀"的时刻），低点出现在普选被框死之后。同一个中国，实力只增未减，认同却先升后降。可见变量不在实力，在互动的性质：被当作伙伴时认同上升，被当作对象（被规划、被惩罚、被"寄望"）时认同下降。断交战是最干净的实验：北京有能力让台湾邦交归零，但 99.5% 的台湾受访者宁可归零也不砸钱护邦交。惩罚只对在乎惩罚的人有效，惩罚本身却在制造不在乎的人。

"边陲东亚"框架是这根线的结构版：归属变更过的地区对"中心"天然警觉，中心越用力拉，边陲越用力挣。这个框架的检验样本是冲绳：不属于两岸问题，却在 2014 年同样爆发对东京的普选反弹，说明这不是"中华圈特有"的现象，是中心-边陲结构的通病。

诚实标注一句：这根线解释离心解释得好，解释"何以尚未走到尽头"就弱一些。台湾的"维持现状"多数、香港本土主义内部的分化，书里承认但着墨少，单靠这根线推不出来，还需要利益与风险计算那根线补位。

作者动机：自序的标题已经写明："当'崛起中国'遇上'太阳伞'"，他的研究历程正好横跨认同变迁最剧烈的年代，而他自己的多重身份（闽生、港长、日本学历、冲绳与台湾任教）让"谁是中国人"于他不只是学术题，更是切身题。这本书的隐含读者其实是大陆读者与决策层：他反复说"寄望于台湾人民"这个思路本身是对的，然后论证现行做法恰恰在赶走人民。这是诤言的写法，不是檄文的写法。

作者盲点：其一，成书于 2017 年，他笔下的"后雨伞时代"还有论述空间，此后香港局势的剧变（2019-2020）超出了书的视野，某些判断（如本土思潮的发展空间）已被现实改写。这本书要当"窗口期的切片"读，不能当现状读。其二，全书对认同的"可逆性"偏乐观，隐含"改变对待方式就能挽回认同"的假设；但认同的代际固化（他自己引的"天然独"概念）恰恰暗示某些窗口关上就不再开，这两个判断之间的张力他没有正面处理。

跨域映射一条：认同不跟实力走、跟对待方式走，这个结构在家庭里最常见。经济上完全依赖父母的成年子女，未必认同父母的安排；父母越用"我养你"施压，子女越把经济依赖和情感认同切割开来。对得上的点：资源可以造成依赖，造不成归属；把依赖误读为归属，是强势一方最常见的误判。书里的"经济融合未带来认同回流"，就是这个误判的地缘版。

行动触发：下次见到"某某地区经济上离不开某某，所以迟早归心"式的论断（商业上也常见：客户离不开我们的供应链，所以关系稳固），拿这本书的检验法过一遍：去查认同/满意度指标是否与依赖度同向。不同向，说明对方在依赖中积累的是离心力，翻脸只差一个替代选项出现。

读者立场：这本书最有价值的是"2008 年高点"这个观察。它把"香港认同问题"从宿命论（回归注定离心）里拉出来，变成可分析的过程（升上去过，为什么又掉下来）。较弱的是文集体例的通病：专栏文章按题归堆，论点在不同篇目里重复出现，紧凑度不如专著；第一部若干篇对国民党路线的分析，时效性已尽，今天读是史料。另外要说明我的判断：作者的边陲框架有解释力，但他对"中心"一侧的内在逻辑（为何明知反效果仍持续施压：内部政治的需要压过对外效果的计算）几乎不拆，这让全书的批评停在"不明智"，没到"为何明知不明智仍为之"，而后者才是更硬的问题。

```
中心施压 ──▶ 边陲反弹（去边陲化）
      │              │
      │       台湾：太阳花 / 天然独
      │       香港：雨伞 / 本土主义
      │       冲绳：反基地普选
      │              │
      ▼              ▼
   实力↑ 认同↓ ← 惩罚制造不在乎惩罚的人
```

全书数据里最扎眼的是那个 0.1%：台湾人认为中华人民共和国是"祖国"的比例。但最值得端详的不是数字本身，是"祖国"这个词的遭遇。

作者在第四问里点了它：同一个词，在两岸三地出现截然不同的认知。北京语境里，"祖国"是不证自明的事实陈述；台湾语境里，它是 0.1% 的极少数认知；香港年轻人那里，它在急速贬值。一个词的三种命运，浓缩了全书的题目："谁是中国人"之争，很大程度上是谁有权定义这些词之争。

攻一下：词语的分歧会不会只是表层，实质还是利益与制度之争？攻完发现恰好相反：词语并非表层，它就是战场本身。安德森讲共同体是"想象的"，意思不是虚假的，是靠共享的符号维系的：一起唱的歌、一起用的词、一起讲的历史。"祖国"这个词在大陆有效，因为它连着共享的叙事；在台湾失效，因为那套叙事在那里没有对应的经验。台湾年轻人成长的每一天，经验告诉他们"我们"的边界在海峡处断开。词的失效不在态度，在经验。所以强制推广词汇（教科书、国民教育）收效甚微：词能下发，经验下发不了。

这里书里有个细节值得放大：游锡堃主张以"台湾"之名取代"中华民国"重建外交，作者点破其中的结构反讽：恰恰是北京不承认含有"中国"意涵的"中华民国"，把这个最后的"中国"符号从台湾的现实里挤了出去，成了台湾社会越来越"倾独"的结构性原因之一。也就是说，"中国"这个词在台湾的最后一个官方载体，是被最想要统一的一方亲手削弱的。要求对方认同"中国"，同时拒绝对方使用"中国"，这个自相矛盾比任何台独论述都更有效地完成了"去中国化"。

日常里同构的事：离婚家庭争夺孩子的称呼。一方坚持孩子必须叫自己"爸爸"，却拒绝承认孩子口中"我们家"包括继父的那个家。孩子最后的解决办法往往是两个都不叫，另起一套自己的称呼。称呼是强求不来的，它只登记既成的情感事实；在称呼上用力，暴露的恰恰是事实上的失势。

合上书的"咦"：这本书名是个问句，读完发现它问的方向和直觉相反。"谁是中国人"通常被读成"谁有资格是"，作者论证的却是"谁还愿意是"。资格由强者定义，意愿只能由弱者交付。而全书的数据说：定义收得越紧，交付得越少。身份认同这个东西，原来和市场上的信用一样，只能挣，不能收。

本篇所引自序四问、"边陲东亚"与"香港共同体"/"准民族主义"概念、中研院 2014 年调查、GDP 超越 G7 时间线、皮尤 2014 年调查、2008 年香港认同高点、0.1% 数据、99.5% 民调（民视直播民调，样本性质为电视互动调查，严谨度低于学术民调）、游锡堃主张与作者评点、安德森生平轶事，均出自原书。本书为 2017 年成书的时评文集，其后香港与两岸局势剧变不在其视野内，所有判断均为当时口径。第三层命题的提炼、家庭与称呼类比、第八层对"词语战场"的展开，是解书者的读法，非作者原文。本书在大陆无出版，所据为台版（时报出版）。

"谁是中国人"问的其实不是谁有资格，是谁还愿意：资格可以定义，意愿只能挣得。
